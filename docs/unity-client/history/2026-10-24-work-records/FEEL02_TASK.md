# 이동·전투 모션과 Unity 맵 직접 사용

사용자 목표: 이동 속도 1.5배, 방향 전환·정지 시 rubber band 완화, 보행·공격 모션 개선, 빈 필드 보완. 추가 요청으로 PR45의 불완전 public Export 경로를 차단하고 Unity 산출물을 서버 공간 설정의 원본으로 사용한다.

## 구현 범위
- 플레이어 6→9 units/s, 서버 0.3→0.45/50ms. ClientTick 송신 주기만 유지하며 제한적 시각 예측을 조정한다. 완전한 ACK 재연으로 표현하지 않는다.
- 기존 파츠 보행·베기·회수·피격 모션. 신규 리깅 제외.
- 6구역 고정 길·낮은 식생·기존 장애물 안 수목. nav/충돌 영역 유지.
- author/layout 없는 Export는 출력 변경 전 거부한다. author 필수 경로는 nav와 metadata를 한 파일로 교체한다.
- 서버 구역 수·크기·중첩·AOI 크기/경계는 Generated/WorldMap.inc에서 직접 파생한다. Cell 실행 자료구조/이웃 AOI/사용자 AI·A*·몬스터 Cell 제한 유지.

## 검증과 종료 조건
독립 코드 리뷰, Unity 컴파일, 직접 영향 자동 3묶음(이동+경계/완전한 public export/파츠 모션), 서버 빌드와 공간 fixture만 수행한다. 구현 동결 뒤 실제 입력 한 배치에서 속도·방향 전환·정지·벽·공격 및 대표 화면을 확인한다. 다른 창 사용 중이면 입력을 보류하고 서버 검증을 계속한다. 이미 통과한 전체 기능 회귀는 반복하지 않는다.

현재맵은 3×2/6구역이다. 3×3 내보내기와 몬스터 배치 콘텐츠까지 포함한 9구역 서버 기동은 구분한다. Export 후 서버 재빌드·정상 전환은 필요하며 런타임 hot reload는 구현하지 않는다.

기존 PR45/46 보존. 이 묶음 로컬 후보의 검증을 마친 뒤 Slack FEEL02 승인 한 번으로 큰 PR에 통합한다. 미완료 단계에서 게시 승인을 요청하지 않는다.

# 포트폴리오 개편 — PR 전 결과

2026-10-19. 사용자 작성 PORTFOLIO_GUIDE를 기준으로 초안의 단일 소개 페이지를 홈·작업 상세 2개·각 화면 이력의 5페이지로 바꿨다. 대표 게임 화면을 먼저 배치하고 공개 본문은 MD 개요/작업별 원본에서 생성한다. 서버 포트폴리오/PPT는 기존 주소로 연결한다. 내부 작업 ID·PR/승인/병합·PID·해시 알림은 공개 본문에서 제거했다. 현재 거래소는 초기 조회 UI인 중간 결과로 표시한다. 회고는 버튼 겹침 수정/사용자의 화면 방향 조정 등 실제 확인한 사례만 포함하며 감상·효율 평가를 만들어내지 않았다.

## 검토와 수정

독립 리뷰 차단 0. 리뷰에서 발견한 화면 이력 이미지의 원본 폭 넘침과 전역 releases ignore로 인한 캡처 누락은 기존 wrapper/폭 규칙과 사이트 경로만의 추적 예외로 수정했다. 첫 화면·갤러리를 브라우저 샘플로 먼저 제공했으며 새 페이지를 대량 확장하지 않았다. 공개 목적·실제 활용/경험의 근거·화면 이력·완료 기준을 GUIDE에 통합하고 공통 지침·현재 정책·워크플로우·역할6개가 참조하도록 반영했다.

## 최종 배치

- 빌드/전체 로컬 링크·앵커·이미지 검사 통과. HTTP 공개 13파일(HTML5/CSS1/PNG7)이 빌드와 바이트 일치, 중첩 디렉터리 index2개 정상. 내부 docs/상위/인코딩 상위 경로3개 404.
- ZIP 3,630,464바이트, 동일한 공개13파일만 MMORPG 하위로 포함. 내부 문서·도구·로그 제외. 날짜 폴더 PNG4개는 검증 원본과 바이트 일치하고 Git 추적 예외 확인. 기존 PNG3개를 보존했다.
- 실제 브라우저 홈→거래소 상세→이력→상세→홈 및 필드 상세→이력→홈 확인. 화면 밖 필드 링크 첫 마우스 시도는 URL이 바뀌지 않아 통과로 처리하지 않았고, 실제 키보드 Enter로 해당 링크와 복귀를 확인했다. 이벤트 핸들러 직접 호출은 없다.
- 1440px 홈/갤러리, 390px 거래소 이력, 768px 필드 상세/이력에서 가로 넘침 없음. 이력 PNG의 자연 크기1280px, 표시폭은 모바일333/태블릿703px로 확인했다. 원본 링크 클릭으로 1280×720 이미지 탭이 열렸고 확인 후 해당 임시 탭만 닫았다. 홈/상세의 대표 이미지도 원본 비율을 유지한다.
- 웹 검증은 게임/DB/Unity 실행을 포함하지 않는다. 변경과 리뷰/검증 대상은 동결했다. 이후 문서 결과 기록 외 제품 변경 없음.

근거는 원본 개발 체크아웃 UnityClient/Captures/portfolio-web-check.txt, portfolio-home.png, portfolio-gallery.png, portfolio-mobile-history.png, portfolio-tablet-history.png에 있다. 원본 내부 증거는 공개 artifact에 넣지 않는다. PORTFOLIO_REVIEW에 검토 파일 해시를 기록했다.

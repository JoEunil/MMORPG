# 체력·마나와 스킬 HUD

요약: 체력·마나의 변화와 스킬 조작을 작은 HUD에서 확인합니다.
상태: 검증된 결과

## 구현한 기능

서버의 체력과 마나를 숫자와 색 게이지로 표시합니다. 스킬 세 개의 버튼을 좁은 HUD 영역에 배치했으며, HP 0·구역 이동·로그아웃 때 기존 상태 처리를 유지합니다.

## 현재 확인한 범위

실제 필드에서 스킬 버튼 사용에 따른 마나 감소와 몬스터 공격에 따른 체력 감소가 숫자와 게이지에 함께 반영되는 것을 확인했습니다. 정상 로그아웃 뒤 표시도 정리됩니다. 숫자 단축키 입력의 서버 반영은 이번 실행에서 확인하지 못했습니다.

## AI Agent 워크플로우

사용자는 목표·기능 범위·화면 방향을 정하고, 총괄 에이전트가 필요한 전문 에이전트에 조사·구현·아트·리뷰·테스트를 배정합니다. 구현과 리뷰를 분리하고, 작업 묶음이 끝나면 실제 Unity 입력과 서버 결과로 확인합니다. 문제가 발견되면 수정한 부분을 다시 검증합니다.

일상적인 구현은 에이전트가 이어서 진행합니다. 사용자는 결과를 보며 방향을 조정하고, PR과 게시 직전에 준비된 변경을 최종 확인합니다.

## 직접 확인하고 바꾼 점

자동 검증을 통과한 거래소에서도 실제 화면을 조작하자 버튼이 겹치는 문제가 드러났습니다. 화면 배치를 고친 뒤 다시 입력해 확인했습니다. 작업 상세에 이처럼 구현과 실제 사용 사이에서 발견한 문제를 함께 남깁니다.

화면 방향은 사람이 계속 조정하고 있습니다. 초기 캐릭터 비율·장비 표현과 거래소의 숫자 목록은 개선 대상으로 남아 있으며, 현재 캡처는 작업 중인 결과입니다.

# 사냥 상태와 전투 HUD

상태: 중간 결과
요약: 서버의 성장 정보와 몬스터 체력을 전투 화면에서 확인합니다.

## 구현한 기능

캐릭터의 체력·마나·레벨·경험치를 표시합니다. HP·MP 게이지는 오른쪽 하단에, 채팅은 왼쪽 하단에 배치했습니다. 스킬 아이콘에는 Z·X·C 키를 크게 표시합니다. 몬스터의 체력 게이지는 서버 상태에 따라 갱신되며 사망·만료·로그아웃 뒤 정리됩니다. 채팅은 전체·구역·귓속말을 선택해 보내며, 최근 메시지가 보이도록 기록이 스크롤됩니다.

세 스킬은 서버가 시전을 알리면 반투명한 면으로 전체 공격 영역을 표시하고, 밝은 영역이 차오르며 준비 시간을 보여줍니다. 공격이 해제되거나 캐릭터가 쓰러지고 구역을 떠나면 표시를 정리합니다. 이동 방향과 반대였던 서버의 수직 타격 판정도 바로잡았습니다.

스킬 아이콘에 마우스를 올리면 공격 형태·범위·MP 소모를 확인할 수 있습니다. 설명은 서버 콘텐츠 자산의 값과 연결하며, 아이콘에서 벗어나거나 가방을 열면 숨깁니다.

몬스터의 체력이 실제로 감소하면 HP바가 잠깐 금색으로 강조됩니다. 몬스터의 기본 공격은 바닥 표시 없이 준비·타격 동작으로 보여줍니다. 특수 원형 스킬은 반투명 면으로 영역을 표시하고, 준비 시간에 따라 밝아지도록 했습니다. 공격이 끝나거나 몬스터가 사라지면 지웁니다.

보스의 부채꼴과 사각 고리 공격에도 단계별 반투명 영역을 표시합니다. 여러 공격이 겹쳐 시작되면 각 예고를 따로 유지하고, 해당 타격 단계에서 정리합니다. 범위는 각 단계에서 서버가 보낸 위치를 기준으로 표시하며, 표시 중에는 보스를 따라 이동하지 않습니다.

## 스킬 모션과 효과

서버의 시전 단계에 맞춰 검을 준비하고, 발동 단계에서 횡베기·회전 베기·내려찍기를 재생합니다. 칼을 휘두를 때 상체·방패·다리가 함께 움직이고, 준비 자세에서 타격과 회수로 부드럽게 이어집니다. 빈 원이나 사각형 대신 검흔과 수직 참격·지면 파쇄를 표시합니다. 전방 스킬은 반투명 면으로 범위와 차징 진행을 보여주며, 발동 효과는 해당 단계의 서버 위치와 방향을 사용합니다. 아이콘에는 서버 시전 응답부터 계산한 쿨타임 추정치를 표시합니다.

새 기사 아트와 UI·효과는 아래 에디터 미리보기에서 볼 수 있습니다. 진입 화면의 Play 확인과 새 동작의 자동 검사·에디터 미리보기를 구분해 기록했습니다. 이후 실제 서버에서 세 스킬의 시전 응답과 MP 차감, 몬스터 HP 감소를 확인했습니다. 모든 몬스터 특수 공격의 실제 교전 확인은 남아 있습니다. 이전 버전의 실제 교전·채팅 기록도 촬영 날짜와 함께 보존합니다.

## 현재 확인한 범위

실제 접속에서 확대된 HP·MP와 Z·X·C 표기를 확인하고, 다른 테스트 클라이언트와 전체·구역·귓속말을 주고받았습니다. 메시지가 쌓인 뒤에도 최신 내용과 수신 대상 표시가 겹치지 않는지 확인했습니다. 이어 생존 상태의 다른 전용 캐릭터로 HUD 위 방향키 이동과 가방·거래소를 연 동안의 이동 차단을 확인했습니다. 아래 채팅 화면은 체력이 0인 이전 접속 기록이며, 생존 이동 화면은 [필드 이동](/MMORPG/work/field-travel/)에서 볼 수 있습니다.

실제 사냥에서 방향키로 접근하고 X 스킬을 두 번 사용해 일반 몬스터 한 마리를 처치했습니다. 서버 상태에서 몬스터 HP가 1500에서 500, 다시 0으로 바뀌고 화면에서 사라졌으며, 캐릭터 경험치는 0에서 10으로 증가했습니다. 두 번째 몬스터는 HP가 500까지 줄었지만 처치하지 않았고 캐릭터 레벨은 1을 유지했습니다. 쿼터뷰 거리에서는 고블린의 가죽·철 장비가 검게 뭉치지 않고 구분되지만, 화면상 크기가 작아 세부 질감은 제한적으로 보입니다.

세 아이콘의 설명을 실제 마우스 조작으로 확인했습니다. C는 길이 12·폭 3의 직선 공격이며 MP 20을 소모합니다. 설명을 보는 것만으로 스킬이 시전되지 않습니다.

### 2026-10-21 — 직선 스킬 방향과 범위

![실제 북쪽 시전 방향을 따라 길게 표시된 직선 스킬 범위](../../../site/media/releases/2026-10-21/line-skill-range.png)

방향키로 정면을 맞추고 C 키를 한 번 눌렀습니다. 서버가 보낸 방향과 같은 쪽에 범위가 나타났고, 범위 안 몬스터의 HP가 1500에서 500으로 줄었습니다. 윤곽은 시전 중 캡처이며 타격 뒤 해제됩니다. 이 화면은 현재 구현 모습으로, 이후 효과와 재질을 개선하면서 이전 기록도 보존합니다.

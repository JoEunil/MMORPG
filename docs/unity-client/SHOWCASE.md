# AI-AGENT Unity 클라이언트 구현 작업

기존 MMORPG 서버에 연결하는 3D 쿼터뷰 Unity 클라이언트를 만들고 있습니다. 사람이 목표와 방향을 정하면 총괄 에이전트가 조사·구현·아트·리뷰 역할을 배정하고, 결과를 실제 게임 흐름에서 확인합니다.

## AI Agent 워크플로우

### 에이전트 구성

- 사용자 — 만들 기능과 우선순위, 화면 방향을 정하고 결과를 판단
- 총괄 Agent — 목표를 작업 단위로 나누고 필요한 전문 역할을 배정, 결과를 모아 다음 작업에 반영
- 기획 Agent — 게임 흐름과 완료 조건을 구체화
- 서버 분석 Agent — 기존 서버의 기능과 연결 규칙을 확인
- 구현 Agent — Unity 클라이언트와 서버 연결을 구현
- 아트 Agent — 캐릭터·배경·UI 표현을 다듬음
- 리뷰 Agent — 구현 결과를 별도로 살펴 문제를 찾음
- 테스트 Agent — 실제 입력과 서버 응답으로 동작을 확인
- 기록 Agent — 확인된 결과와 화면을 공개 자료로 정리

### 작업 흐름

목표를 정하고, 필요한 역할을 배정해 구현·검토한 뒤 실제 흐름으로 확인합니다. 확인한 결과는 다음 작업과 화면 기록에 반영합니다.

- 목표 설정 — 사용자가 기능·우선순위·표현 방향을 결정
- 작업 설계 — 총괄 Agent가 완료 조건을 정리하고 조사·구현·아트 작업을 배정
- 구현과 검토 — 에이전트가 결과를 만들고 별도 리뷰에서 문제를 확인
- 묶음 검증 — 실제 입력과 서버 응답을 확인하고 필요한 부분을 수정
- 결과 갱신 — 확인한 기능과 화면을 다음 작업에 반영

### 피드백

- 리뷰·검증에서 문제 발견 — 근거와 재현 흐름을 구현 작업에 전달해 수정
- 사용자 피드백 — 목표나 화면 방향을 조정하고 이후 작업 범위에 반영

## 큰 목표와 진행 흐름

- 연결·기본 플레이 — 기본 흐름 확인 · 로그인, 캐릭터 선택, 월드 진입과 구역 이동을 연결했습니다.
- 게임 화면과 조작 — 개선 중 · 이동·전투·채팅, 인벤토리와 거래소 화면을 다듬고 있습니다.
- 사냥터와 콘텐츠 — 코드 검증 완료 · 필드 확장과 몬스터·캐릭터 속도 조정을 반영했으며 실플레이 확인은 남았습니다.
- 실제 플레이 확인 — 화면 확인 대기 · 새 HUD, 세 종류 채팅, 확장 필드의 실제 화면을 확인할 예정입니다.

## 지침 변경 이력

- 카툰풍에서 판타지 MMORPG로 — 초기 카툰 방향을 거두고 캐릭터·배경·UI를 정통 판타지 분위기로 다듬기로 했습니다.
- 마우스 이동에서 키보드 조작으로 — 클릭 이동 대신 방향키 이동과 Z/X/C 스킬 입력을 선택했습니다.
- 텍스트 표시에서 게임 UI로 — 기능 검증용 텍스트 화면을 아이콘·HUD 중심으로 바꾸고 있으며 일부 정보 표시는 확인용으로 유지합니다.
- 작은 반복에서 기능 묶음으로 — 작은 변경마다 하던 테스트와 전달을 줄이고, 관련 기능을 모아 검토·검증하기로 했습니다.

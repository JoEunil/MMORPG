# 초반 사냥에서 원형기와 직선기 역할 확인

## 검토 후보 — 추가 실입력은 미배정

기존 스킬·몹·스폰 데이터를 기준으로 사냥 구성의 다음 변경 근거를 검토했다. 원형·직선 스킬의 실제 피해는 이미 확인됐고, 지금 단계에서 반복 전투만을 새 작업으로 배정하지 않는다. 수치와 맵 배치는 근거가 부족해 유지한다.

## 확인된 근거

- 실제 사냥에서 캐릭터 5012는 레벨 1, EXP 0에서 시작해 일반 몬스터 한 마리를 처치하고 EXP 10을 얻었다. X는 type 0 HP 1500을 한 번에 500으로 낮췄고 두 번째 시전에 처치했다. 이후 C 한 번도 같은 type 0에 1000 피해를 줘 HP 500을 남겼다. 실제 전투의 HP·EXP 변화는 [HUNT_LIVE_RESULTS.txt](HUNT_LIVE_RESULTS.txt)와 [직선 스킬 검증](LINE_AIM_RESULTS.txt)에 있다.
- 현재 서버 데이터에서 X(skill 1)는 반경 8 원형, 공격 배율 100, MP 20, 쿨다운 120틱(6초)이다. C(skill 2)는 길이 12·폭 3 직선, 같은 공격 배율·MP, 쿨다운 80틱(4초)이다. 둘 다 주변 몬스터를 맞힐 수 있다. 클라이언트 Z/X/C는 서버 슬롯 0/1/2에 연결된다.
- 6개 Zone은 각각 5×5의 22-unit 셀을 쓰고, 현재 y-major 스폰 형상은 모든 Zone에서 같다. 안전 시작 셀과 중앙 보스 셀은 비워 두며, 나머지 셀의 일반/강한 몬스터 수는 위치마다 다르다. 이를 여섯 개 별도 배치나 새 밀도 설정으로 복제할 근거는 없다.
- 이 한 번의 사냥으로 레벨업, 회복, 드롭, 재접속 후 성장 저장은 확인되지 않았다. 이 묶음은 그 규칙을 추가하거나 전제하지 않는다.

## 향후 실제 변경이 생겼을 때만 병합할 확인 후보

다음에 스킬 역할이나 몬스터 배치를 실제로 변경한 경우에만, 그 변경의 실입력 배치에 아래 관찰을 합칠 수 있다. 지금 별도 실행하지 않는다. 전용 캐릭터 한 번 접속으로, HP 1500인 type 0 몬스터 두 마리 이상이 가까이 있는 구간을 찾는다. 우선 X를 한 번 써 원형 범위의 적중 수와 각 HP delta를 기록하고, 살아남은 같은 무리를 C의 직선 범위에 맞춰 한 번 공격해 다시 기록한다. 두 번째 공격 전 대상별 HP와 위치를 남겨 첫 공격 영향과 구분한다. 캐릭터 HP/MP/EXP도 함께 기록한다. 일반 이동·서버 판정은 그대로 사용하며 좌표나 전투 결과를 주입하지 않는다. 같은 접속의 정상 종료까지 포함한다.

완료는 두 스킬의 서버 확정 적중 수와 HP 변화가 구분돼 기록되고, 관측하지 않은 결과를 추정하지 않은 상태다. 두 마리 배치가 없거나 C 방향에 맞춰 정렬할 수 없으면 그 한 번의 입력에서 확인 불가로 기록하고 반복 시전으로 맞추지 않는다. 자동 테스트는 제품 수치를 고칠 때 직접 영향 있는 최대 2개만 후보로 두며, 이번 기획 단계에서는 실행하지 않는다.

## 판단 경계

비교 결과로 X의 넓고 쉬운 원형 범위와 C의 길고 좁은 방향 범위가 서로 다른 상황에서 유용한지 판단한다. 실제 대상 수·HP·MP·대기시간이 역할 차이를 보여줄 때만 기존 skill 1/2의 authoring 값 한 곳을 최소 조정 후보로 만든다. 전투 배열의 공통 패턴이 확인되면 기존 셀 형상을 활용하고, 새 Zone별 density 배열·새 성장 규칙·새 서버 시스템은 만들지 않는다. 표본이나 배치가 부족하면 수치 변경을 보류한다.

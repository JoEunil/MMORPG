# 아이템과 거래소 화면

요약: 인벤토리와 거래소 매물을 살펴보고, 가격을 확인해 구매를 요청한 뒤 구매품을 별도로 수령하는 흐름을 연결했습니다.
상태: 중간 결과

## 구현한 기능

- 인벤토리 — 5종 아이템 카드·상세 정보·I 키 열기와 닫기
- 거래소 — 종류·페이지별 매물과 판매자·등록 정보
- 내 매물 — 현재 캐릭터 매물·새로고침·판매 검색 복귀
- 구매 — 가격 확인, 서버 완료와 가방 반영 구분
- 판매 취소·아이템 반환·대금 수령 — 요청별 서버 결과, 등록비 미환급
- 불명확한 거래 결과 보존과 자동 구매·취소 재요청 방지
- 화면 전환 — B 키 열기와 닫기, 가방·거래소 중 하나만 표시

## 현재 확인한 범위

실제 서버의 매물·내 매물·가격·재화 부족·빈 수령함을 확인했고, 성공 거래·취소·아이템 반환은 자동 검사로 확인했습니다. 아이템 사용·장착과 거래 등록은 지원하지 않습니다.

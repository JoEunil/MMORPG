# 인벤토리

요약: 아이템을 살펴보고, 사냥으로 얻은 포션을 사용해 체력을 회복하는 가방 화면입니다.
상태: 중간 결과

## 대표 화면

![일반 몬스터를 처치해 얻은 HP 포션을 선택한 실제 가방 화면](../../../site/media/releases/2026-10-29/growth-potion-before-use.png)

몬스터를 처치해 레벨이 오른 뒤 HP 포션을 선택한 실제 게임 화면입니다. 포션 그림·이름·수량과 사용 버튼을 함께 확인할 수 있습니다.

## 구현한 기능

- 아이템 그림·이름·수량 카드와 선택 항목 상세 정보
- 새로고침 뒤 같은 아이템 선택 유지, 수량 갱신, 항목 변경 시 선택 해제
- 월드 진입 후 HP·MP 포션 바로가기 수량 확인
- I 키로 열고 닫기, Esc로 닫기, 거래소와 패널 상호 배타
- HP·MP 포션: 각각 3,000 회복, 숫자 1·2로 사용, 공용 쿨타임 2초
- 사망·해당 자원 최대 상태에서 포션 소비 차단
- 빈 가방과 조회 오류 구분, 실패 시 재조회와 새로고침 안내
- 거래소 전환 중 조회 재사용, 늦은 수령·취소 결과 뒤 열린 가방 갱신

## 현재 확인한 범위

실제 거래 포션 수령과 사냥 보상 포션 사용 뒤 HP 회복·수량 감소를 확인하고, 재접속 후 상태 보존도 확인했습니다. I/B/Esc 전환과 선택·갱신·오류 복구는 각각 실제 입력 또는 자동 검사로 확인했습니다.
MP 포션과 두 슬롯·공유 쿨타임은 자동 검사로 확인했으며, 최신 묶음의 실제 게임 확인은 진행 중입니다.
아이템 장착은 제공하지 않습니다.

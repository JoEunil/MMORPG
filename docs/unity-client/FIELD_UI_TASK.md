# 필드 정보 화면 정리

CLASSIC01 게시 승인 대상은 codex/classic-mmorpg-motion의 ee85f3f로 고정한다. 이 후속은 codex/classic-field-ui에서 계속 저작하며 이전 승인을 자동 소비하지 않는다.

- 바꿀 동작: 필드의 큰 좌표/내부 ID 표시를 구역·조작 안내로 줄이고, 퇴장 버튼을 같은 작은 헤더 안에 배치한다.
- 최소 수정: C02WorldScreen의 표시 문자열, C02SceneBuilder의 기존 WorldHud 배치, 관련 기존 검사 기대 문구. Scene은 Coordinator만 수정한다.
- 보존: 실제 캐릭터/Zone/좌표의 검증·상태·소유권과 네트워크/서버 수치. 기존 검사에서 내부 상태와 위치 assertion은 유지한다.
- 확인: 컴파일·고정 diff 리뷰, 이미 있는 순서 뒤바뀜 상태 검사와 실제 Canvas 영역/문구 가독성만 확인한다. 새 로그인·전투·거래소 회귀는 반복하지 않는다.
- 전달: 다음 관련 필드/아트 묶음에 포함하며 별도 작은 PR을 만들지 않는다.

독립 리뷰 차단0, 컴파일 오류0, 기존 Full/Zone 도착순서 시나리오2통과(동일검사2경우). 캐릭터ID/내부ID/좌표의 실제 상태 assertion은 그대로 유지했다. Editor에서 실제Canvas 부모,360x88패널/328x68텍스트/106x28버튼을 확인했다. 새로그인·전투·거래소회귀와실게임캡처를반복하지않았고사이트에는기존검증캡처를유지한다.

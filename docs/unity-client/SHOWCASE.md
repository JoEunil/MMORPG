# AI-AGENT Unity 클라이언트 구현 작업

기존 게임 서버와 직접 만든 2D 클라이언트를 바탕으로 AI Agent에 3D 클라이언트 구현을 맡겼습니다. 요구와 플레이 피드백으로 수정한 과정을 담았습니다.

## 이번 작업의 결과

기존 클라이언트의 이동·몬스터·스킬·채팅·월드 진입을 3D 화면으로 연결하고, Unity에 없던 인벤토리·거래소도 서버에 연동했습니다. 사용자는 우선순위와 화면·조작 방향을 정했고, Agent는 필요한 조사·구현·아트·리뷰·검증을 맡아 실행 피드백을 반영했습니다.

## 먼저 만든 기반: 기존 2D Unity

기존에 직접 구현한 2D 클라이언트에는 이동·몬스터·스킬·채팅·월드 진입이 들어 있었습니다. Unity 인벤토리와 거래소 화면은 없었습니다. 이번 작업은 이 기반과 서버를 이어 3D 클라이언트로 확장했습니다.

![기존에 직접 구현한 2D Unity 클라이언트](../../site/media/legacy/unity-client.png)

아트·기획을 자세히 지시하기 어려운 항목은 여러 안을 비교하고, 사용자가 고른 요소를 묶음 작업에 반영했습니다. 아래는 실제 선택 기록의 화면이며 게임 플레이 장면은 아닙니다.

![전투 표현의 두 방향을 비교한 선택 화면](../../site/media/releases/2026-10-25/decision-support-combat.png)

전투·마을·사냥터·UI의 화면 시안과 전투 안내, 길 진입, 가방 상세 구성을 함께 비교했습니다.

![HUD의 미니맵·스킬·HP와 MP 표현을 비교한 시안](../../site/media/releases/2026-10-26/hud-options-comparison.png)

선택 시안은 방향을 정하기 위한 예시입니다. 실제 적용 화면과 기능별 이력은 [전투와 상태 UI](/MMORPG/work/player-hud/)에서 확인할 수 있습니다.

## 작업 방식을 바꾼 이유

요구를 구체적으로 전달하고, 실행 결과를 사람이 확인하는 과정이 필요했습니다. 특히 조작감과 아트 방향은 테스트 통과만으로 판단하기 어려워 비교 시안과 실제 플레이 피드백을 함께 사용했습니다.

[작업 중 느낀 점과 바꾼 방식 보기](/MMORPG/experience/)

## AI Agent 워크플로우

사용자는 목표·우선순위를 정하고 비교안과 결과를 판단합니다. 총괄 Agent는 완료 조건을 정리해 필요한 역할을 배정하고 결과를 통합합니다.

### 에이전트 구성

- 사용자 — 목표·우선순위와 선택·결과 판단
- 총괄 Agent — 범위 정리·역할 배정·결과 통합
- 의사결정 지원 Agent — 비교안과 사용자 선택 연결
- 기획 Agent — 플레이 흐름·완료 조건 구체화
- 서버 분석 Agent — 서버 기능·통신 규칙 조사
- 구현 Agent — Unity 기능·서버 연결 구현
- 아트 Agent — 선택된 캐릭터·배경·UI 표현 구현
- 리뷰 Agent — 변경 내용 독립 검토
- 종합 검수 Agent — 기획·아트·UI·UX·조작 관점 검수
- 테스트 Agent — 정한 범위의 입력·응답 확인
- 기록 Agent — 확인된 결과와 화면 정리

## 하나의 기능이 만들어지는 흐름

요구를 확인 기준으로 구체화하고 필요한 역할이 구현·검토·검증합니다. 기획·아트 방향은 비교안을 거쳐 사용자가 고르며, 답변을 기다리는 동안 독립 작업을 이어갑니다.

### 작업 흐름

- 목표와 확인 기준 정리
- 방향 비교 — 중요한 기획·아트 선택안은 장단점을 종합 검수하고 사용자가 선택
- 구현과 독립 리뷰
- 변경된 동작 중심 검증
- 종합 검수와 결과 정리

### 피드백이 돌아오는 방식

- 리뷰·테스트 문제는 근거와 함께 원 구현 담당이 수정합니다.
- 종합 검수 피드백도 원담당이 반영하고 영향 구간을 다시 확인합니다.
- 사용자 선택과 플레이 피드백을 후속 작업 조건에 반영합니다.

## Agent 활용 지표

새 Agent 실행은 새로 만든 Agent에 작업을 맡긴 횟수, 후속 작업 실행은 기존 Agent를 다시 실행한 횟수입니다. 전체 실행은 두 수의 합이며 메시지·테스트·토큰 사용량을 뜻하지 않습니다. [전체 역할별 집계 보기](/MMORPG/process/#agent-usage)

## 지침 변경 이력

- 2026-10-31 — 종합 검수 피드백은 원담당이 반영하고 영향 구간을 다시 확인합니다.
- 2026-10-27 — 실제 게임 화면과 조작 경험을 중심으로 결과를 정리했습니다.
- 2026-10-25~26 — 기획·아트 시안을 비교하고 선택한 표현을 제작에 반영했습니다.
- 2026-10-21 — Unity에서 내보낸 맵 통행 데이터를 서버 판정에 연결했습니다.

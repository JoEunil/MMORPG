실제 게임 화면과 작업별 기록을 모아, AI와 함께 만든 클라이언트가 어떻게 바뀌었는지 보여줍니다.

## 프로젝트

기존 게임 서버에 연결하는 3D 쿼터뷰 MMORPG 클라이언트를 만들고 있습니다. 사람이 목표와 방향을 정하고, AI 역할들이 서버 동작을 조사하고 구현·아트·리뷰를 나눠 맡습니다. 결과는 실제 화면과 서버 응답으로 확인합니다.

## 함께 만든 방식

작업마다 필요한 역할을 정해 협업합니다. 사람은 범위와 시각 방향을 결정하고, AI는 조사·구현·아트 제작·독립 리뷰를 나눠 진행합니다. 마지막에는 실제 입력과 서버 결과를 확인하고, 발견한 문제를 고쳐 화면에 반영합니다.

## 직접 확인하고 바꾼 점

자동 검증을 통과한 거래소에서도 실제 화면을 조작하자 버튼이 겹치는 문제가 드러났습니다. 화면 배치를 고친 뒤 다시 입력해 확인했습니다. 작업 상세에 이처럼 구현과 실제 사용 사이에서 발견한 문제를 함께 남깁니다.

화면 방향은 사람이 계속 조정하고 있습니다. 초기 캐릭터 비율·장비 표현과 거래소의 숫자 목록은 개선 대상으로 남아 있으며, 현재 캡처는 작업 중인 결과입니다.

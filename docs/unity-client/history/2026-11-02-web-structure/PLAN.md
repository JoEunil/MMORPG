# 결과 페이지 구조 변경 계획

2026-11-02 · 대상: ResultPageRevision/source · 기존 PR63에 모을 로컬 초안

## 목표와 경계

방문자가 기존 기반, 실제 기능, Agent 활용 방식을 짧은 제목과 화면으로 이해하게 한다. 홈을 1단계, 상단 메뉴 또는 홈 카드로 여는 상세를 2단계로 제한한다. 화면 이력은 같은 상세에서 펼치며 별도 페이지를 늘리지 않는다. 게임·서버·몬스터 AI는 수정하지 않는다.

기존 CONTENTTOUR01/r1의 20a64c1 게시 요청 이후 추가 피드백이므로 이 계획의 변경까지 승인된 것으로 취급하지 않는다. 최종 검수 후 새 후보를 같은 Slack 묶음에서 제시한다.

## 1. 홈 첫 화면

| 항목 | 변경 |
| --- | --- |
| 소개 | 한 문장: 기존 2D 기능의 3D 확장과 가방·거래소 연동 |
| Agent 작업 방식과 기록 | 제목·소개 바로 아래에 진입 배치 |
| 기존 2D 클라이언트 | 접힌 소개 대신 실제 화면을 항상 노출 |
| 기능 범위 비교 | 기존 2D / 현재 3D의 기능 유무를 짧은 표로 표시 |
| 작업과 결과 | 기능별 동일한 비율·높이의 이미지와 명사형 기능 목록 |

2D 화면과 Agent 기록 진입 모두 홈 상단에 있어야 한다. 큰 도식 전체를 홈에 펼쳐 2D 화면이 아래로 밀리게 하지 않는다. 선택 시안·회고·작업 방식의 반복 요약은 홈에서 제거한다.

## 2. Agent 작업 방식과 활용 기록

- **Agent 워크플로우:** 역할·배정·피드백 관계를 한 장의 이미지로 표시.
- **활용 기록:** 비교 시안과 선택 사례를 지표와 함께 배치. 홈의 ‘선택한 방향을 결과로’를 이 안에 통합.
- **지침 변경:** 날짜 — 핵심 한 줄만 표시.

‘하나의 기능이 만들어지는 흐름’의 중복 도식은 제거한다. 총괄은 하나의 실제 역할이며 ‘총괄 통합 Agent’라는 별도 역할을 만들지 않는다. 통합은 총괄의 책임으로만 표시한다. 생성 이미지에 잘못된 역할·화살표가 있으면 사용하지 않는다.

## 3. 콘텐츠 둘러보기

- 스킬 3종, 거래소 등록·취소, 채팅 3종의 실제 GIF 8개 유지.
- 각 항목은 기능명과 입력 → 결과 한 줄.
- GIF 펼침은 같은 화면에서 처리하고 원본 파일 이동 링크는 제거.
- 실제 촬영, 예시, 확인하지 않은 범위를 혼동하지 않게 짧게 구분.

## 4. 기능별 상세와 이력

- ‘구현한 기능’은 명사형 목록으로 통일.
- 비용·재화·지원 범위처럼 비교하는 정보는 표, 조작 순서는 짧은 단계 목록 사용.
- 과거 이력은 날짜 — 핵심 한 줄, 이미지는 기본 접힘.
- 장문 원본과 과거 캡처는 내부 아카이브에 보존.
- 이미지의 원본 이동 링크와 본문 내 연쇄 탐색 링크 제거.
- 경험 회고 페이지도 반복 소제목·장문 설명을 축약하되 사용자 경험의 의미를 보존.

## 5. 탐색과 공통 UI

- 상단 메뉴와 홈 기능 카드만 주요 페이지 진입으로 사용.
- 본문 목차, 반복 ‘더 보기’, 이전/다음 기능, 푸터 중복 링크 제거.
- 접근성용 본문 건너뛰기와 같은 페이지 이력 펼침은 유지.
- 홈 카드의 이미지는 같은 16:9 틀에 contain 처리. 크기 예약으로 로딩 중 배치 이동 방지.
- 상세 이미지는 한 컬럼 안에서 동일한 틀과 여백 사용. 원본 비율을 강제로 늘리거나 핵심 화면을 잘라내지 않음.

## 6. 이미지 제작과 선택

먼저 이 계획을 새 종합 검수 Agent가 검토한다. 필수 피드백을 반영한 뒤 아래 3개 후보를 제작한다. 후보를 사용자에게 연속 노출하지 않고 검수 담당자가 비교·선택한 안만 통합한다.

| 후보 | 제작 방식 | 비교 목적 |
| --- | --- | --- |
| A | 정확한 벡터 이미지, PC/모바일 각각 구성 | 동일한 상자·글자 크기, 정확한 연결, 작은 화면 가독성 |
| B | 이미지 생성, 세로 배정 트리 | 사용자의 목표와 총괄 배정 관계를 먼저 읽는 구성 |
| C | 이미지 생성, 가로 제작·검수 흐름 | 병렬 분담과 동일 담당자에게 돌아가는 피드백 강조 |

공통 제약: 실제 역할만 사용, 장식·질감·입체감 제외, 동일 계층 상자 크기 통일, 작은 설명 배제. 검토·검증은 역할 묶음이며 매번 모두 순차 실행한다고 표현하지 않는다. 중요한 기획·아트 선택은 사용자가 판단한다.

선택 기준 순서: 사실 정확성 → 화살표 의미 → PC/모바일 가독성 → 간결함 → 페이지와의 시각적 일관성. A도 자동 통과하는 대체안이 아니며 같은 기준으로 검수한다. 후보 간 역할·문구를 같게 유지한다. 어느 안도 통과하지 못하면 원 제작 담당이 필수 피드백을 반영해 수정한다. 이미지 제작 도구의 출력을 검증 없이 게시하지 않는다.

## 실행·검수 순서

1. 새 종합 검수 Agent: 계획의 요구 누락·모순·우선순위 검토.
2. 제작: 승인된 계획에 따른 후보 이미지와 Markdown·생성기 초안 통합.
3. 같은 검수 Agent: 후보 이미지 비교·선택. 필수 피드백은 원 제작 담당자가 수정.
4. 검증: 사이트 엄격 빌드 1회, 대표 홈·상세·워크플로우의 PC/모바일 확인. 기존 게임 테스트는 반복하지 않음.
5. 같은 검수 Agent: 실제 최종 화면·탐색·설명 길이 검수. 통과 후 결과와 미리보기 제출.

## 완료 조건

- 홈에서 2D 화면과 Agent 작업 기록 진입을 쉽게 찾음.
- 일반 소개는 한 문장, 기능은 목록, 비교는 표로 정리됨.
- 상세 간 연쇄 탐색 없이 홈에서 각 상세에 접근함.
- 불필요한 이미지 하이퍼링크가 없음.
- 워크플로우 이미지의 상자·글자 크기가 일관되고 허구 역할이 없음.
- 관련 캡처·원문·실제 GIF 8개를 보존하고 최종 종합 검수 통과.

# 거래소 조회 화면의 첫 버전

요약: 실제 서버의 거래소 매물과 빈 결과를 조회하는 초기 UI입니다.

상태: 중간 결과

## 구현한 기능

- 포션·무기/방패·방어구 종류를 선택해 서버 매물을 조회합니다.
- 이전·다음 페이지와 새로고침으로 조회 조건을 바꿉니다.
- 매물의 아이템 번호·수량·가격을 표시하고 검색 결과가 없으면 빈 결과를 안내합니다.
- 창을 닫거나 다시 열 때 이전 요청의 응답이 새 조회를 덮지 않도록 처리합니다.

## 현재 확인한 범위

이 페이지는 서버 조회를 처음 연결한 화면 기록입니다. 유형·페이지 변경과 새로고침을 실제 입력으로 확인했습니다. 목록 선택과 상세 표시를 추가한 모습은 [아이템과 거래소 화면](/MMORPG/work/item-market/index.html)에서 볼 수 있습니다.

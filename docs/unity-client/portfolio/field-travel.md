# 로그인과 필드 이동

요약: 로그인·캐릭터 선택·월드 불러오기를 구분하고, 방향키로 쿼터뷰 필드를 탐험하는 화면을 만들고 있습니다.

상태: 중간 결과

## 구현한 기능

- 계정 로그인, 캐릭터 선택, 월드 불러오기 화면을 각각 나눴습니다.
- 서버에서 받은 캐릭터만 선택하며, 입장을 취소하면 로그인 화면으로 돌아갑니다.
- 방향키 이동과 Z·X·C 스킬 입력을 연결하고, 캐릭터 움직임을 부드럽게 이어 표시합니다.
- 기존 좌표를 유지하며 필드를 여섯 구역으로 넓히고, 방향키 이동 중 서버가 구역 전환을 결정하도록 바꿨습니다. 새 구역의 플레이어·몬스터 상태가 모두 준비되면 조작을 다시 엽니다.
- 맵의 장애물·통로와 구역 구성을 Unity에서 편집하고, 서버가 내보낸 데이터를 직접 사용하도록 연결했습니다. 구역 크기를 서버에서 별도로 맞추지 않습니다.
- 여섯 구역 중 한 곳을 몬스터 없는 마을로 나누고, 쓰러진 캐릭터가 마을로 돌아와 체력과 마나를 회복하는 기능을 추가했습니다.

## 이동과 모션

이동 속도를 높이고 방향 전환·정지 때 위치를 되감는 보정을 줄였습니다. 입력 방향과 화면 보정을 분리하고, 보행의 흔들림과 공격 준비·베기·회수 모션을 다듬었습니다. 로컬 서버에서 직선 이동과 직각 전환·반전·정지를 확인했으며, 다양한 네트워크 지연에서의 조작감은 계속 확인할 부분입니다. 필드에는 길과 낮은 식생, 기존 장애물 주변 수목을 고정 배치했습니다.

## 현재 확인한 범위

실제 로그인과 캐릭터 선택을 거쳐 방향키 이동·정지, 세 스킬의 서버 시전 응답을 확인했습니다. 생존 상태에서 기존 필드에서 북쪽 필드를 거쳐 확장 필드까지 이동했고, 구역을 바꿔도 서버 좌표와 배경이 이어지는 것을 확인했습니다. HUD 위에 마우스를 두어도 방향키로 이동하며, 가방·거래소를 열면 이동을 멈춥니다. 여섯 구역 전체를 왕복한 결과는 아니며 사냥 난이도와 처치 보상 확인은 남아 있습니다. 이전 실행에서는 HP가 0이 되면 이동·공격을 막고 안내와 게이지를 유지하는 것도 확인했습니다.

맵 내보내기와 서버 주도 전환은 자동 검증에 이어 실제 서버 연결로도 확인했습니다. 살아있는 캐릭터의 이동 요청으로 장애물 통과가 막히고, 인접 구역을 왕복할 때 양쪽 구역의 상태를 받는 것을 확인했습니다. 이후 Unity의 방향키 입력 경로로도 마을과 인접 사냥터를 왕복하고, 새 구역에서 조작을 이어갈 수 있는지 확인했습니다. 같은 접속에서 벽 앞 정지와 가방·거래소를 연 동안의 이동 차단도 확인했습니다.

### 2026-10-23 — 진입 화면 아트

![성채 배경과 금속 프레임을 적용한 실제 Unity 로그인 화면](../../../site/media/releases/2026-10-23/knight-login.png)

성채와 기사의 배경 삽화, 가죽 바탕과 금속 프레임으로 진입 화면을 바꿨습니다. 기존 로그인·캐릭터 선택·월드 불러오기 흐름은 유지합니다. 배경 기사는 메뉴용 삽화이며, 게임에서 움직이는 3D 모델은 전투 화면 기록에서 따로 볼 수 있습니다. 이번 화면은 Play 모드의 무입력 확인으로 촬영했습니다.

### 2026-10-22 — 이동과 공격 모션 보완

![방향키 이동을 확인한 현재 필드 화면](../../../site/media/releases/2026-10-22/field-movement-refined.png)

방향키를 누르면 이동하며, 방향을 바꾸면 입력한 방향을 바라봅니다. 이번 화면은 이동 속도와 정지 동작을 확인한 중간 결과입니다.

![서버 시전에 맞춰 검을 휘두르는 캐릭터](../../../site/media/releases/2026-10-22/strike-motion-refined.png)

공격 입력 후 준비·베기·회수 모션을 재생하고, 스킬 아이콘에 재사용 대기 시간을 표시합니다.

### 2026-10-22 — 맵 장애물과 이동 입력

![방향키로 접근한 캐릭터가 내보낸 석축 벽 앞에서 멈춘 실제 Unity 화면](../../../site/media/releases/2026-10-22/field-wall-input.png)

Unity에서 만든 벽의 통행 정보를 서버와 공유합니다. 방향키를 누른 채 벽에 접근해도 통과하지 않으며, 마을과 인접 사냥터를 왕복한 뒤에도 이동과 화면 조작을 이어갈 수 있는 것을 확인했습니다.


### 2026-10-22 — 사냥터에서 마을로 귀환

![사냥터에서 쓰러진 캐릭터에게 마을 귀환 버튼이 나타난 실제 화면](../../../site/media/releases/2026-10-22/town-before-return.png)

쓰러진 상태로 사냥터에 접속한 뒤 마을 귀환 버튼을 눌렀습니다. 다시 접속하는 것만으로는 회복되지 않습니다.

![마을 귀환 후 안전 지역 표시와 가득 회복된 체력·마나가 보이는 실제 화면](../../../site/media/releases/2026-10-22/town-after-return.png)

서버가 마을 이동을 확정한 뒤 체력과 마나가 모두 회복됐고 경험치는 유지됐습니다. 마을에는 몬스터가 나타나지 않으며, 화면의 성문은 기존 배경을 사용했습니다. 새 마을 건물이나 NPC를 추가한 결과는 아닙니다.

### 2026-10-22 — 쓰러진 캐릭터의 필드 진입과 로그아웃

![체력이 0인 캐릭터의 필드 진입 후 패배 안내와 로그아웃 버튼이 표시된 실제 화면](../../../site/media/releases/2026-10-22/map-hp0-field.png)

체력이 0인 상태로 접속하면 이동·스킬 입력을 막고 패배 안내를 표시합니다. 로그아웃 버튼을 누르면 연결을 정리하고 로그인 화면으로 돌아갑니다. 이 화면은 생존 이동이나 자동 구역 전환을 확인한 기록은 아닙니다.

### 2026-10-20 — 확장 필드로 이동

![생존 상태로 확장 필드에 도착해 체력·마나와 구역 이동 버튼을 확인한 실제 화면](../../../site/media/releases/2026-10-20/expanded-field-alive.png)

![필드에서 HP0 상태와 하단의 세 스킬 아이콘을 표시한 실제 게임 화면](../../../site/media/releases/2026-10-20/classic-field-hp0.png)

실제 접속에서 이동과 스킬을 사용한 뒤 사냥으로 HP가 0이 된 화면입니다. 방향키와 스킬 입력이 멈추고, 퇴장 안내가 표시되는 것을 확인했습니다. 이후 확대된 체력·마나와 스킬 키 표기는 [전투와 상태 표시](/MMORPG/work/player-hud/)에서 볼 수 있습니다.

# AI Agent 활용 경험

클라이언트를 만들며 요구 전달·검증·의사결정 방식을 조정했습니다.

## 경험과 개선

| 느낀 점 | 바꾼 방식 |
| --- | --- |
| 당연하게 여긴 조건도 명시해야 반영 | 위치·크기·단축키와 입력 뒤 기대 결과를 함께 전달 |
| 자동 검증과 실제 조작감의 차이 | 동작 확인과 사람의 플레이 평가를 분리 |
| 기획·아트 방향을 말로 설명하기 어려움 | 여러 시안을 묶어 비교·선택하고 제작에 반영 |
| 작은 작업과 반복 확인으로 흐름 중단 | 관련 기능을 묶고, 바뀐 부분만 검증 |

## 남은 한계

- 미세한 끊김·이동 보정·공격 타이밍은 실제 플레이 피드백 필요
- 시안과 실제 적용 화면의 구분
- 한 번의 입력 검증으로 모든 지연 환경을 확인할 수 없음

## 검토 기준

- 리뷰 의견과 실제 코드·계약의 일치 여부
- 다음 수정자가 이해하고 고치기 쉬운 구조
- 사용자 선택을 기다리는 동안 독립 작업 진행

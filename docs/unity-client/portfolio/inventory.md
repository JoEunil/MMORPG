# 인벤토리

요약: 아이템 그림과 수량을 살펴보고, 선택한 항목의 정보를 확인하는 가방 화면입니다.
상태: 중간 결과

## 대표 화면

![2026-10-26 에디터 예시 — 청록 선택 면과 오른쪽 아이템 상세를 적용한 가방](../../../site/media/releases/2026-10-26/bag-b.png)

현재 가방 배치를 보여주는 샘플입니다. 아이템과 수량은 예시이며 실제 서버에서 확인한 가방은 빈 목록입니다.

## 구현한 기능

AI Agent 작업에서 Unity 인벤토리 화면과 서버 조회를 새로 연결했습니다. 직접 구현한 기존 2D 클라이언트에는 인벤토리 화면이 없었습니다.

- 아이템 그림·이름·수량을 카드로 보여주고, 선택 항목은 오른쪽 상세 영역에서 확인합니다.
- 새로고침 후 같은 아이템의 선택을 유지하고 최신 수량을 보여줍니다. 아이템이 사라지거나 바뀌면 선택을 해제합니다.
- I 키로 열고 닫으며 Esc로 닫을 수 있습니다. 거래소와 동시에 띄우지 않습니다.
- 서버의 빈 가방 결과와 조회 오류를 구분합니다. 오류 뒤 한 번 다시 조회하고, 계속 실패하면 새로고침을 안내합니다.

가방과 거래소 판매 화면을 빠르게 전환해도 같은 조회를 재사용합니다. 아이템 수령·판매 취소가 뒤늦게 완료되면 열린 가방에 최신 목록을 반영합니다.

## 현재 확인한 범위

패널 전환 중 조회 공유, 수령·판매 취소의 늦은 완료와 최신 목록 갱신은 자동 검사로 확인했습니다. 실제 서버에서 성공 거래·아이템 반환까지 확인한 결과와는 구분합니다.

화면에는 다섯 아이템의 그림과 표시 정보가 연결되어 있습니다. 새로고침 시 선택·수량과 오류 후 초기화는 자동 UI 검사로 확인했습니다. 실제 서버에서 받은 가방 응답은 빈 목록이어서, 아이템이 든 가방을 실제 서버 자료로 표시하는 것은 아직 확인하지 못했습니다. 화면 기록에는 빈 결과와 초기 조회 오류를 그대로 남겼습니다.

최신 실제 접속에서도 첫 조회 오류 뒤 다시 조회해 빈 가방 응답을 받았습니다. I·B·Esc 키는 Unity 입력 시스템을 통한 자동 조작으로 가방·거래소 전환과 닫기를 확인했습니다. 아이템 보유 목록과 거래 뒤 실제 아이템 반환은 계정에 해당 조건이 없어 확인하지 못했습니다.

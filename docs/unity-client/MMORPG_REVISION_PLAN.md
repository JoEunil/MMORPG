- 가방은 I, 거래소는 B로 열고 닫는다. 채팅/입력창에서 단축키가 발동하지 않게 하며, 패널이 게임 이동/스킬 입력과 겹치지 않도록 한다. 현재 요청을 이미 구현한 것으로 표시하지 않는다.
- 기존 서버 아이템 ID를 조사해 각각 아이콘·슬롯·선택 상세 표시를 준비한다. 거래소도 아이콘·수량·가격·선택/확인 UI로 구성한다. 지원되는 아이템에 맞는 자산을 제작/선별하며 이름/수량/가격 같은 필요한 텍스트는 유지한다. 장착/소비·새 아이템 효과는 서버의 실제 지원 없이 추가하지 않는다.

# 정통 판타지 MMORPG 개편 계획

2026-10-20 사용자 요청을 반영한 현재 기준. 이번 변경은 계획·운영 기록이며 게임 구현이나 모델 설정 전환을 완료한 것이 아니다. 이전 카툰/스타일라이즈드 방향과 클릭 이동 우선 정책보다 아래 기준을 우선한다. 기존 완료 기능과 미게시 거래소·콘텐츠 후보는 보존한다.

## 목표와 범위

- 시각 방향은 리니지1 계열에서 느껴지는 정통 판타지 MMORPG로 잡는다. 기존 3D 쿼터뷰 기반에서 성인 캐릭터 비례, 갑옷·무기 세부 형태, 자연스러운 재질·지면·식생, 절제된 장식 UI를 사용한다. 전체 화면을 어둡게 하는 것 자체를 목표로 삼지 않는다. 정확한 시리즈별 세부 취향은 대표 화면 확인에서 조정한다.
- 방향키 지속 입력으로 이동하고 키를 놓으면 정지한다. UI/채팅 입력 중 이동·스킬을 막고 동시 방향 입력의 속도 증가를 방지한다. 서버 이동 예산·좌표·4방향 시전 계약과 일치시킨다. 마우스는 UI·대상 선택에 사용하며 지면 클릭 이동은 기본 조작에서 제외한다.
- 현 서버의 스킬 슬롯 3개는 Z/X/C로 변경한다. V는 요구 키 영역으로 기록하지만 실제 연결할 기존 행동을 정하기 전에는 비워 둔다. 네 번째 스킬이나 가짜 슬롯을 추가하지 않는다.
- 텍스트 나열형 표시를 HP/MP/경험치 바, 스킬 아이콘·쿨다운, 인벤토리 슬롯, 거래소 목록·선택·가격·확인 UI로 바꾼다. 이름·수량·가격·도움말 등 필요한 글은 유지한다. 서버 확정 상태만 표현하고 미지원 기능을 활성화하지 않는다.
- 레벨 디자인은 기존 레벨·경험치·캐릭터/몬스터 수치·스킬·아이템 계약을 기준으로 초반 사냥의 이동 시간, 적 밀도, 처치 시간, 위험 구간, 보상과 성장 체감을 맞추는 작업으로 정의한다. 새 직업·장착·소비·드롭 규칙은 현 서버 지원을 확인한 뒤 필요한 범위를 따로 정한다.
- 플레이어/몬스터 이동·공격 간격과 추적/어그로 해제/복귀 등 현재 AI를 서버 기준으로 조정한다. 화면 애니메이션만 느리게 만들어 속도 불일치를 숨기지 않는다. 실제 이동 가능 영역과 맞는 맵부터 만들며 서버에 없는 충돌·경로 탐색이 완성된 것처럼 장벽을 배치하지 않는다.

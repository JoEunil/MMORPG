# C08 — 기존 Zone 간 이동

목표: 서버의 실제 경계까지 이동한 캐릭터가 Zone 1↔2를 왕복하고, 새 구역의 확인된 상태가 도착한 뒤 조작을 재개한다. 글로벌 좌표와 HP/MP·기존 스킬 쿨다운을 보존한다.

범위: 실제 격자 이웃/공유 경계 검증, 전환·종료의 원자성, 오래된 구역 패킷 구분, ClientCore 전환 상태 및 Unity 표시/입력 잠금. 기존 채팅·인벤토리·전투를 보존한다. 포털·순간이동·새 Zone·지형 충돌·DB 쓰기는 제외한다.

서버/ClientCore/프로토콜 최소 후보는 최신 최종 승인 정책에 따라 로컬 구현·검증한다. push·PR은 구체 diff·독립 리뷰·테스트·복구안 준비 후 Slack에서 요청한다. 강제 종료/DB 초기화/운영 배포는 수행하지 않는다.

소유: 총괄은 작업 카드·통합·Editor 단독 조작. 서버 분석자는 C08_SAFETY.md, 클라이언트 담당은 초기 C08_CLIENT_PLAN.md. 제품 파일은 설계 확정 후 명시 배정한다. 기존 미커밋 정책·타인 변경은 보존한다.

완료 조건: 잘못된 이웃·먼 좌표 전환 거절, 종료 경합 시 세션/캐릭터 부활 없음, 이전 방문의 Full/Delta/Monster/Action 무시, 새 Full 전 이동/스킬/조회 차단, 왕복 시 좌표/HP/MP/스킬 상태 보존 및 정상 퇴장. 화면이 존재한다는 사실만으로 성공 처리하지 않는다.

검증 계획: 구현·독립 리뷰 종료까지 컴파일과 정적 검토만 한다. 이후 C++ 대상 회귀와 Unity 공통 회귀를 각 한 번, 실제 로그인→경계까지 정상 이동→Zone2→확인된 새 상태→Zone1→퇴장을 한 배치로 실행·캡처한다. 환경 조건 미충족/실패는 근거와 함께 구분한다. 예상 실행 비용: 빌드 수 분, 단위 회귀 수 초, 실제 왕복 수 분. 통과 후 근거 없는 반복 없이 종료한다. 수정 발생 시 영향 범위만 재검증한다.

복구: 후보 빌드를 별도 폴더에 보존하고 기존 C07 실행 이미지를 덮어쓰지 않는다. 정상 종료·포트 비움·로그/WAL 보존 gate 후 후보 기동, 실패 시 확인된 정상 종료 뒤 기존 이미지로 복구한다. 기존 q 종료 경고는 숨기거나 guard를 완화하지 않는다.

현재: 구현·독립 리뷰·회귀·실제 입력 및 캡처 완료. C08_RESULTS.md의 단계별 근거와 한계를 따른다. GitHub 반영 최종 승인은 아직 요청 전이다.

# 인벤토리

요약: 아이템 확인·포션 사용·장비 장착.
상태: 중간 결과

철검·방패 동시 장착 · 서버 재시작 후 유지.

## 구현한 기능

- 서버 데이터의 아이템 이름·분류·효과와 기존 아이콘
- 무기·방패·갑옷 각 1슬롯, 장착·해제와 공격·방어 합계 표시
- 방패 2%·갑옷 3%의 피해 감소, 합산 5%
- 장착품 판매 차단, 가방 수량 보존, 재접속·서버 정상 재시작 후 유지
- 아이템 그림·이름·수량 카드와 선택 항목 상세 정보
- 장착 배지·아이템별 ATK/DEF 효과·두 포션 슬롯의 공용 남은 시간
- 새로고침 뒤 같은 아이템 선택 유지, 수량 갱신, 항목 변경 시 선택 해제
- 월드 진입·귀환 후 HP·MP 포션 바로가기 수량 자동 조회
- I 키로 열고 닫기, Esc로 닫기, 거래소와 패널 상호 배타
- HP 1,500·MP 500 회복, 숫자 1·2로 사용, 공용 쿨타임 6초
- 사망·해당 자원 최대 상태에서 포션 소비 차단
- 빈 가방과 조회 오류 구분, 실패 시 재조회와 새로고침 안내
- 거래소 전환 중 조회 재사용, 늦은 수령·취소 결과 뒤 열린 가방 갱신

## 포션 종류

| 등급 | HP 회복 | MP 회복 | 사용 |
| --- | ---: | ---: | --- |
| 초급 | 1,500 | 500 | 가방·1/2키 |
| 중급 | 3,000 | 1,000 | 가방 |
| 상급 | 4,500 | 1,500 | 가방 |

공용 쿨타임 6초. 중·상급의 상점·획득 경로는 추가하지 않았습니다.

## 현재 확인한 범위

철검·방패의 구매·수령·장착·판매 차단·서버 재시작 복원·해제를 실제 게임에서 확인했습니다. 포션 사용·수량 표시도 기존 구현을 유지합니다.

갑옷과 합산 방어·피해 판정은 자동 검사로 확인했습니다. 갑옷 실전 장착과 실제 전투 피해 측정은 이번 확인에 포함하지 않았습니다.

등급 포션은 서버 사용·콘텐츠 공유·가방 사용을 자동 검사로 확인했습니다. 새 포션의 실제 보유·소비 검증은 하지 않았습니다.

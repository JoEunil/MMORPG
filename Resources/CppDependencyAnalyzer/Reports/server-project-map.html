분석 방법과 분류 기준

분석 Clang이 빌드 설정에 맞춰 소스와 헤더를 읽습니다. 코드 구조(AST)에서 상속, 멤버 타입, 정적으로 해석된 호출을 연결합니다.

클래스 연결 기준은 의존 관계에 따라 노드를 배치합니다. namespace별 지도는 클래스가 선언된 namespace를 따릅니다.

프로젝트 프로젝트 묶음은 클래스가 속한 프로젝트를 따릅니다. 프로젝트 참조 지도는 .vcxproj의 참조 항목을 사용합니다.

외부 라이브러리 외부 코드 폴더에서 실제로 읽은 헤더를 근거로, 라이브러리마다 프로젝트 지도에 주황색 노드 하나를 표시합니다.

Visual Studio 필터 선언 파일을 .vcxproj.filters의 프로젝트·필터별로 묶습니다. 선의 숫자는 연결된 클래스 쌍 수입니다. 프로젝트 묶음에서 초록색 상속선은 다른 프로젝트의 Interface 필터에 속한 타입을 가리킵니다.

직접·간접으로 사용하는 타입이 많은 후보부터 정렬합니다.

# 내 매물 조회와 검색 전환

요약: 현재 캐릭터의 매물만 조회하고, 새로고침하거나 판매 검색으로 돌아갑니다.
상태: 검증된 결과

## 만든 것

- 판매 검색과 내 매물을 오가는 탭
- 내 매물 새로고침과 정상 빈 결과 안내
- 창을 닫거나 접속을 바꾼 뒤 도착한 응답을 무시하는 처리

## 해결한 문제

조회 요청에 캐릭터 번호를 직접 보내지 않고 서버가 접속 중인 캐릭터를 확인하도록 연결했습니다. 탭을 바꾼 뒤 이전 조회 응답이 새 화면을 덮지 않도록 요청 종류와 번호를 함께 확인합니다.

## 에이전트를 활용한 과정

총괄 Agent가 서버 계약 조사, 구현, 독립 리뷰와 실행 검증을 나눠 배정했습니다. 리뷰에서 현재 폰트가 새 한글 라벨을 표시하지 못하는 문제를 발견해 기존 영문 라벨에 맞췄습니다. 작업을 묶어 검증한 뒤 두 테스트 캐릭터로 실제 화면을 조작했습니다.

## 결과

두 캐릭터 모두 내 매물이 없는 정상 결과를 확인했습니다. 새로고침·판매 검색 복귀·닫기 중 위치와 체력·마나도 유지됐습니다. 실제 소유 매물이 있는 화면은 아직 확인하지 않았으며, 등록·구매·취소·수령 기능은 포함하지 않습니다.

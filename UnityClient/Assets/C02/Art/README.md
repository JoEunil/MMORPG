# V02 guard and outpost representative

Traditional fantasy guard direction: adult approximately 7.3-head anatomy (unscaled crown2.05/head0.28/hip1.03/shoulder1.65), layered steel armor, mail, worn brown leather and faded crimson cloth. Natural field with pale masonry gate/walls, irregular roadside rocks, branch-based pines, rolling distant terrain and a textured soil/grass edge. Opaque leather-tone UI with thin aged-bronze framing and light parchment input fields. One representative scene and one static guard; no art-set expansion. SUNWARD is a cosmetic sample wordmark.

Source/tools: original procedural geometry authored in C02SceneBuilder with Unity Mesh/Texture2D/AssetDatabase APIs, applied through the assigned Unity CLI and live Editor. V02_ mesh assets are original profile surfaces, curved armor, cloth folds, curved shield, irregular stone, branch/needle clusters, grass blades and terrain. V02_MailLinks texture is128x128 original linked-ring grayscale pattern; V02_StoneGrain is128x128 low-contrast Perlin stone grain; V02_GroundBlend is512x512 original soil/grass blend. No downloaded artwork, third-party models, paid assets, image generator or external 3D generator. Built-in primitive geometry retains Unity's license requirements. New mesh/texture content was authored for this repository; existing project font/licensing stays unchanged.

Materials: GuardSteel metallic0.68/smoothness0.32; WornSteelEdge0.67/0.36; AgedBronze0.65/0.15; OiledLeather/FadedCrimson/Chainmail; WeatheredLimestone/FoundationStone/EarthAndGrass/PineBark/PineNeedles/Moss/MountainHaze. URP/Lit. Fabric/foliage use two-sided culling rather than opposed triangles sharing normals. Texture assets use mipmaps, trilinear filtering, repeat wrapping and anisotropy4; no external importer or package changes. Legacy V01 assets remain but do not describe the current V02 appearance.

Coordinates: server x/y map to Unity x/z unchanged. OwnCharacter keeps its original root/pivot at ground y=0; visible V01Hero has an unscaled crown2.05, scale1.2 in the field and2.1 in the cosmetic login preview, facing local-Z. No rig, animation, movement, combat or new collision behavior. Added primitive colliders are removed; authored MeshRenderer objects have no colliders. The field decoration remains centered around server(10,10), not an authoritative map boundary/collision declaration. Legacy FieldPlane and Capsule reference objects remain, with their renderers hidden.

Login diorama is cosmetic, placed at (1000,0,1000) and rendered by Main Camera. It is labeled CHARACTER & ENVIRONMENT PREVIEW. The real world retains the C02 Zone + own Full state gate and its separate quarterview camera. Existing capsule renderer is hidden; existing reference object is retained. World data/HUD strings remain server-driven.

UI: Canvas scale reference1280x720 and existing LiberationSans TMP asset. No new serif font was available in the project, so restrained existing-font typography was used. Actual sign-in/list/entry controls retain names, references, raycast targets and a masked vertical list for the existing ten rows. Decorations are noninteractive. Field HUD uses actual existing server status; no invented health, currency, character data or feature buttons.

Validation boundary: the user explicitly resumed execution tests for V02. Artist still performs Edit Mode authoring/compilation/static inspection and full camera+Canvas preview only; Coordinator owns actual Play/input/server validation after freeze. Captures/v02-editor-composition.png and v02-editor-composition-r2.png are Editor visual previews, not server-entry evidence. Preliminary V01 captures remain historical. The r2 preview was directly inspected; grass normal cancellation, sparse foliage, exaggerated masonry, excessive metal highlights and panel transparency were corrected before freezing.

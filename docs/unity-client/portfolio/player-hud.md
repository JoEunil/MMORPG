# 사냥 상태와 전투 HUD

상태: 중간 결과
요약: 서버의 성장 정보와 몬스터 체력을 전투 화면에서 확인합니다.

## 구현한 기능

캐릭터의 체력·마나·레벨·경험치를 표시합니다. 하단 HP·MP 게이지를 확대하고 세 스킬의 Z·X·C 키 표기를 키웠습니다. 몬스터의 체력 게이지는 서버 상태에 따라 갱신되며 사망·만료·로그아웃 뒤 정리됩니다. 채팅은 전체·구역·귓속말을 선택해 보내며, 최근 메시지가 보이도록 기록이 스크롤됩니다.

## 현재 확인한 범위

실제 접속에서 확대된 HP·MP와 Z·X·C 표기를 확인하고, 다른 테스트 클라이언트와 전체·구역·귓속말을 주고받았습니다. 메시지가 쌓인 뒤에도 최신 내용과 수신 대상 표시가 겹치지 않는지 확인했습니다. 현재 계정의 저장된 HP가 0이므로 이번 화면은 생존 상태의 이동·전투 검증을 의미하지 않습니다.

이전 실행에서는 Ring 사용과 마나 소모, 몬스터 체력 감소와 퇴장 후 게이지 정리를 확인했습니다. 몬스터 처치와 경험치 증가 결과는 아직 확인하지 않았습니다.

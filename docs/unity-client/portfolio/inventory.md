# 인벤토리

요약: 가방에 담긴 아이템을 그림과 수량으로 살펴보고 선택한 아이템의 정보를 확인합니다.

상태: 중간 결과

## 구현한 기능

- 아이템 그림·이름·수량을 목록에 표시하고 선택한 아이템 정보를 상세 영역에 보여줍니다.
- I 키로 가방을 열고 닫습니다. 거래소와 동시에 표시하지 않습니다.
- 서버 조회 결과에서 빈 가방과 조회 오류를 구분합니다.

## 현재 확인한 범위

클라이언트에는 다섯 아이템의 그림과 표시 정보가 연결되어 있습니다. 실제 서버에서 확인한 가방 응답은 빈 목록이며, 아이템이 든 가방을 서버와 연결해 보여주는 화면은 아직 확인하지 않았습니다. 아래는 서버의 빈 결과와 초기 조회 오류를 구분해 남긴 화면 기록입니다.

# 필드 진입로 시각 개선

목표: 성문에서 첫 굽이까지 기존 이동 동선이 풀밭과 구분되도록 대표 구간만 개선한다. 서버 좌표·스폰·충돌·이동 판정은 바꾸지 않는다.

소유: field_route_art는 C18 제작 도구와 필요한 최소 셰이더, C02SceneBuilder의 호출 한 줄만 담당한다. Coordinator만 ROOT Editor, Scene, mesh/material/meta와 캡처를 다룬다. 기존 지면 텍스처와 사용자 WIP는 보존한다.

확인 범위: 독립 코드 리뷰·컴파일, 동일 구도의 에디터 정적 전후 화면 한 쌍, 채택 후 전용 메시·collider 없음·재적용 무변경 확인. 기능·서버 변경이 없어 로그인과 기존 전투/가방 회귀는 반복하지 않는다. 카메라는 local(16,22), 실제 이동 카메라와 같은 (12,16,-12) 시선 방향, orthographic size 13이다. 에디터 비교를 실제 게임 동작 검증으로 설명하지 않는다.

첫 후보: 기존 WornTrail 재질을 재사용한 58정점 ribbon. 컴파일·독립 읽기 리뷰를 통과했으나 실제 화면에서 단단한 띠 같은 경계가 보여 미채택했다. 실험 메시·소스와 Scene 백업은 ROOT Builds/Entry-Trail에 보존했다. 해당 새 자식과 자체 생성 메시만 제거한 뒤 Scene의 원본 백업과 바이트 일치를 확인했다. 기존 지면/재질은 수정하지 않았다. 첫 미채택 화면은 직접 확인했으나 after PNG 경로를 최종 비교에 재사용해 별도 파일로 보존하지 못했다.

두 번째 후보는 가장자리·양 끝의 투명도 완화로 한정했다. 기존 흙 원본을 재사용하되 기존 재질을 덮어쓰지 않는 전용 shader/material을 사용한다. 최종 정적 비교에서 딱딱한 띠 경계가 사라진 소폭 보강으로 채택했다. ENTRY_TRAIL_RESULTS.txt에 확인 범위와 제한을 남겼다. 신규 리깅·구매·이미지 생성·서버 변경은 없다.

게시: 기존 UI01은 별도 동결 범위로 유지한다. 이 실험을 승인된 PR41이나 UI01에 임의 포함하지 않는다.

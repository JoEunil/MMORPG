# 아트·화면 구성 담당

승인된 게임 방향에 맞춰 에셋·재질·조명·UI/VFX 표현을 개선한다. 공통 지침, [BRIEF.md](../BRIEF.md)와 공개 화면 작업 시 [PORTFOLIO_GUIDE.md](../PORTFOLIO_GUIDE.md)를 따른다. 작업 범위와 질문은 Coordinator에게 전달한다.

## 책임과 소유권

- Coordinator가 지정한 ArtSource·아트/UI/VFX 파일만 수정한다. Scene·Prefab·Material 통합은 정확한 파일과 Editor 소유권을 배정받은 경우만 맡는다. 제품 로직·패킷·서버 판정·게임 수치는 수정하지 않는다.
- 중요한 아트 방향은 [선택지 비교 절차](../WORKFLOW.md#기획아트-방향-선택)에 따라 같은 조건의 저비용 시안으로 제안한다. 선택한 요소를 대표 화면에 적용한 뒤 확장하며, 기존 선택 안의 작은 수정은 다시 묻지 않는다.
- 대량 제작 전에 실제 게임 카메라·목표 해상도에서 대표 구역/화면 샘플을 만든다. 실루엣, 재질, 조명, 가독성, 겹침과 시야 가림을 확인한 뒤 확장한다.
- 전투 VFX와 예고는 서버의 범위·방향·phase와 맞아야 하며 캐릭터나 조작 정보를 가리지 않는다. 시각 장식으로 충돌이나 서버 지원을 암시하지 않는다.
- 신규 리깅은 범위에서 제외한다. 기존 캐릭터와 모션을 보존하며 에셋·재질·조명·기존 파츠 연출을 우선 개선한다.
- 외부/생성 리소스의 출처·라이선스·사용 조건과 필요한 비용을 기록한다. 콘셉트 이미지를 실제 구현 결과로 제시하지 않는다.

## 인계

배치한 파일과 연결 상태, 실제 게임 카메라에서 확인한 화면, 가림·크기·애니메이션 결과, 남은 아트/통합 작업을 Coordinator와 테스트 담당에게 전달한다. 사람의 미술 방향 평가가 필요한 경우 비교 화면과 선택지의 장단점을 제안한다.

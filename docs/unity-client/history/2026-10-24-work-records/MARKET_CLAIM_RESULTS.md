# 내 매물 대금 수령 — 검증 기록

기준 브랜치: `codex/market-proceeds`  
검증 대상 기준 commit: `0f9b96dee074127d3f6e12a34ce15d44d391bf5e`와 그 위의 미커밋 작업 트리. 최종 Git 전달 상태는 HANDOFF.md에서 관리한다.

## 결과

- 거래소에서 내 매물을 조회하고 판매된 매물을 선택해 대금 수령 요청을 보내며, 서버 응답을 선택 매물과 연결해 화면에 반영한다. 응답을 받지 못한 경우 완료로 표시하거나 자동 재요청하지 않는다.
- 서버의 최종 수령 상태 `4`는 이미 수령했거나 수령 대기 매물이 없다는 뜻이다. 이 응답만으로 새 지급이 완료됐다고 단정하지 않는다.
- 독립 리뷰에서 상태 표시와 응답 오류 전파 문제를 찾아 수정했다. 최종 리뷰는 차단 사항 없이 끝났다.

## 검증 근거

- Unity 자동 검증 2개가 통과했다. native 검증 2개도 최종 통과했다. 첫 native 실행의 세션 정리 fixture가 격리된 zone 세션을 제거하지 못해 종료 조건을 보완한 뒤 해당 항목만 다시 실행했다.
- 실제 Unity 흐름은 로그인 후 필드에 진입하고, 매물 검색 결과 30개와 빈 내 매물 결과를 확인한 뒤 화면을 캡처하고 정상적으로 창을 닫았다. 수령 버튼은 비활성이었고 서버가 반환한 문구는 “You have no listings.”였다.
- 지정 테스트 계정에 수령 가능한 판매 매물이 없어 실서버 대금 지급은 검증하지 않았다. 지급 성공 경로는 자동 fixture로만 확인했다. DB 직접 쓰기와 실제 지급 요청은 없었다.
- 실제 화면 캡처: `site/media/releases/2026-10-20/market-proceeds-empty.png`.

## 범위와 상태

DB 스키마·저장 프로시저·경제 규칙은 바꾸지 않았다. GitHub 반영·PR·공개 배포는 이 검증 기록만으로 완료 처리하지 않는다.

## 실행 한계와 복구

- ClientCore DLL은 Release 빌드 출력과 SHA256 45D921900AB54D8F5F23F798BCA9509DF03749AC0F960C1D458E7AEA093B5252로 일치한다. 후보 MainServer는 SHA256 5CC6280B6E5297B77AAB4318321D531598E666F606A924E087F1057ADC4E1E7D, 로컬 서버3096에서 준비 완료와9999수신 확인. 로그인17184도 복구했으며 MySQL·Redis는 재시작하지 않았다. 운영 배포가 아니다.
- 내부 Claim 응답 ABI와 외부 opcode30/31이 바뀌므로 Core/Cache/MainServer와 ClientCore를 함께 빌드한다. 이전 클라이언트의 검색/내매물 계약은 유지한다. 복구는 로컬서버 정상종료 후 이전 전체빌드·DLL·클라이언트로 교체하며 이미 COMMIT한 정상 정산을 DB초기화로 되돌리지 않는다.
- 빌드 포함 경로와 Windows 출력 경로를 보완했다. 단위 실행 파일은 기존 GoogleTest 라이브러리를 재사용했으며 다운로드·설치는 하지 않았다. 실행 중인 서버와 공유한 DLL의 반복 복사에서 공유 위반이 발생해 기존 검증된 DLL을 유지하고 단위 빌드의 사후복사만 제외해 최종 build exit0을 확인했다. 최초 테스트 실행은 GoogleTest DLL 경로 누락으로 시작되지 않았고 기존 설치 경로를 그 프로세스에만 제공해 해결했다.
- Unity 실입력의 수동 관찰자가 비직렬화 myListings를 SerializedObject로 읽어 NRE를 낸 기록은 보존한다. 해당 관찰자를 제거하고 reflection 읽기로 교체했으며 제품·서버 동작은 바꾸지 않고 같은 로그인에서 계속 관찰했다. 신규 제품 오류로 분류하거나 로그를 지워 숨기지 않았다.
- 정상 로그아웃의 CancelIoEx1168은 사용자 확인에 따른 기존 비차단 종료 진단이다. 다른 오류를 일괄 무시하지 않는다.
- 공개 원본·이미지·이력을 갱신하고 site 생성 검증 통과. 실제 브라우저 데스크톱/모바일(본문폭375/scroll폭375, 이미지1280원본→333표시)과 이력 링크 탐색 확인. 로컬 미리보기는 http://127.0.0.1:8790/MMORPG/work/item-market/index.html 이며 정식 Pages 공개 상태와 구분한다.

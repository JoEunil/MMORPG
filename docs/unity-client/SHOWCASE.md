# AI-AGENT Unity 클라이언트 구현 작업

기존 MMORPG 서버와 직접 만든 2D 클라이언트를 바탕으로, AI Agent를 활용해 3D 쿼터뷰 클라이언트를 개발하고 있습니다. 구현한 기능과 실제 화면, 작업을 이어가며 달라진 모습을 모았습니다.

## AI Agent 워크플로우

### 에이전트 구성

- 사용자 — 만들 기능과 우선순위, 화면 방향을 정하고 결과를 판단
- 총괄 Agent — 목표를 작업 단위로 나누고 필요한 전문 역할을 배정, 결과를 모아 다음 작업에 반영
- 기획 Agent — 게임 흐름과 완료 조건을 구체화
- 서버 분석 Agent — 기존 서버의 기능과 연결 규칙을 확인
- 구현 Agent — Unity 클라이언트와 서버 연결을 구현
- 아트 Agent — 캐릭터·배경·UI 표현을 다듬음
- 리뷰 Agent — 구현 결과를 별도로 살펴 문제를 찾음
- 테스트 Agent — 실제 입력과 서버 응답으로 동작을 확인
- 기록 Agent — 확인된 결과와 화면을 공개 자료로 정리

### 작업 흐름

목표를 정하고, 필요한 역할을 배정해 구현·검토한 뒤 실제 흐름으로 확인합니다. 확인한 결과는 다음 작업과 화면 기록에 반영합니다.

- 목표 설정 — 사용자가 기능·우선순위·표현 방향을 결정
- 작업 설계 — 총괄 Agent가 완료 조건을 정리하고 조사·구현·아트 작업을 배정
- 구현과 검토 — 에이전트가 결과를 만들고 별도 리뷰에서 문제를 확인
- 묶음 검증 — 실제 입력과 서버 응답을 확인하고 필요한 부분을 수정
- 결과 갱신 — 확인한 기능과 화면을 다음 작업에 반영

### 피드백

- 리뷰·검증에서 문제 발견 — 근거와 재현 흐름을 구현 작업에 전달해 수정
- 사용자 피드백 — 목표나 화면 방향을 조정하고 이후 작업 범위에 반영

## Agent 활용 지표

새 에이전트를 실행하거나, 쉬고 있던 에이전트에게 후속 작업을 맡긴 횟수입니다. 총괄의 직접 작업과 실행 중 메시지는 포함하지 않습니다.

기록을 시작한 뒤의 전체 활성화를 워크플로우의 7개 역할로 묶었습니다. 총괄이 직접 수행한 테스트·기록은 전문 Agent 호출 수에 더하지 않습니다. 역할을 확인할 수 없는 과거 기록은 별도로 표시하며, 토큰 사용량은 제공되지 않아 집계하지 않습니다.

## 지침 변경 이력

- 카툰풍에서 판타지 MMORPG로 — 초기 카툰 방향을 거두고 캐릭터·배경·UI를 정통 판타지 분위기로 다듬기로 했습니다.
- 마우스 이동에서 키보드 조작으로 — 클릭 이동 대신 방향키 이동과 Z/X/C 스킬 입력을 선택했습니다.
- 텍스트 표시에서 게임 UI로 — 기능 검증용 텍스트 화면을 아이콘·HUD 중심으로 바꾸고 있으며 일부 정보 표시는 확인용으로 유지합니다.
- 기사 아트와 스킬 연출 강화 — 신규 리깅 없이 판금·재질·조명을 보완하고, 횡베기·회전 베기·내려찍기를 서로 다른 동작과 효과로 구분합니다.
- 작은 반복에서 기능 묶음으로 — 관련 기능을 모아 필요한 부분만 검증하고, 매 단계 멈추지 않고 검토 가능한 큰 작업 단위로 전달하기로 했습니다.
- Unity 맵을 서버와 공유 — Unity에서 작성한 맵을 서버로 내보내고, 충돌과 구역 전환은 서버가 같은 데이터를 기준으로 처리하도록 바꿨습니다.
- 몬스터 AI와 클라이언트의 역할 분리 — 몬스터 AI는 사람이 직접 개선하고, Agent는 맵 내보내기와 클라이언트 표현을 맡도록 범위를 나눴습니다.
- 코드 양보다 단순한 구조 — 기능을 더하기 전에 기존 구조를 확인하고, 중복 코드와 불필요한 계층을 줄이는 기준을 추가했습니다.
- Agent 활용 기록 남기기 — 역할별 활성화 횟수와 확인된 결과를 기록하고, 제공되지 않은 토큰 사용량은 추정해서 채우지 않기로 했습니다.

## 작업 둘러보기

화면을 선택하면 구현한 기능을 볼 수 있습니다. 이전 모습은 각 작업의 화면 이력에 남겼습니다.

- [필드 이동](portfolio/field-travel.md) — 캐릭터 선택 뒤 월드에 진입해 구역을 이동하는 플레이 흐름.
- [전투와 상태 표시](portfolio/player-hud.md) — 스킬 시전과 서버 전투 결과, 캐릭터·몬스터 상태를 확인하는 화면.
- [인벤토리](portfolio/inventory.md) — 아이템 그림·수량과 선택 상세를 보여주는 가방 화면.
- [거래소](portfolio/market.md) — 매물 조회부터 구매·취소·수령까지 거래소의 화면 변화와 확인 범위.
- [콘텐츠 편집](portfolio/server-content.md) — 스킬·몬스터 설정과 맵의 통행·충돌 데이터를 Unity에서 편집해 서버로 내보내는 도구.

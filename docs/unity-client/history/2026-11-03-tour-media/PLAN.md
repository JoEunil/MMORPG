# 화면 비율과 콘텐츠 보강

- 홈 비교표: 클라이언트 기준의 기존 기능 / 새로 추가한 기능으로 통일.
- 활용 기록: 같은 크기의 작은 미리보기와 같은 페이지 전체 시안 펼침. 원본 비율·현재 워크플로우 보존.
- 글자: 제목·설명·지표의 크기와 굵기 구분.
- 추가 GIF: 실제 원본의 사냥 보상·주변 몬스터 미니맵을 확대. 기존 영상의 확대임을 짧게 표시.
- 새 촬영 후보: 몬스터 접근·교전·처치, 가방의 HP 포션 사용. 실제 화면에서 동작·수치 변화를 확인한 장면만 추가.
- Unity는 현재 연결된 Editor가 없고 다른 게임이 실행 중이어서 새 촬영 입력 시점을 비동기로 확인 중. 그동안 웹 작업은 진행.
- 확인: 엄격 빌드와 PC·모바일의 미리보기/전체 시안 펼침, 추가 GIF·설명 일치. 게임 테스트 중복 실행 없음.
- 같은 종합 검수 담당이 원본·표현·화면을 확인한 뒤 결과 제출. 게시 승인은 기존 묶음의 최종 후보에만 적용.

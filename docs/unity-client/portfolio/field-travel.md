# 필드와 월드 이동

요약: 로그인과 캐릭터 선택을 거쳐 월드에 들어가고, WASD·방향키로 쿼터뷰 필드를 이동합니다.
상태: 중간 결과

## 대표 화면

![연결한 외곽 성벽과 성벽 주변 잔디 — 실제 맵의 에디터 미리보기](../../../site/media/releases/2026-11-08/connected-town-walls-preview.png)

외곽 성벽의 틈·모서리 연결과 벽 주변 잔디 보완. 실제 맵의 에디터 미리보기입니다.

## 구현한 기능

- 계정 로그인·캐릭터 선택·월드 진입 흐름
- WASD·방향키 이동과 Q·E·R 스킬 입력
- 여섯 구역과 서버 공유 통행·충돌 데이터
- 서버 확정 구역 이동과 새 구역 상태 수신
- 몬스터 없는 마을과 사망 후 귀환 흐름
- 사냥터별 권장 레벨·몬스터 능력치·경험치·골드 보상
- 일반·강화 몬스터 차등 배치와 두 사냥터의 보스
- 자신 중앙 고정·카메라 방향 정렬 미니맵과 개체·북쪽 표시
- 미니맵 클릭으로 여는 전체 월드 지도와 현재 위치·사냥터 권장 레벨 표시

## 이동과 모션

- 이동 속도·방향 전환 보정과 보행·공격 모션
- 길·낮은 식생·기존 장애물 주변의 수목 배치

## 현재 확인한 범위

실제 서버에서 로그인·여섯 구역 왕복과 마을 복귀, 재접속 상태 유지, 벽 충돌·UI 개방 중 이동 차단·사망 귀환을 확인했습니다. 자동 방향키 입력으로 확인했으며, 다양한 네트워크 지연의 조작감과 성장 균형은 미확인입니다.

최신 Windows 빌드에서는 마을에 접속해 미니맵 클릭, 현재 위치 표시, 전체 지도 닫기와 다시 열기를 확인했습니다.

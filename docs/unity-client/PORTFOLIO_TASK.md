# 포트폴리오 사이트 전면 개편

현재 목적·콘텐츠·실제 경험/평가의 근거·캡처 이력·대표 화면/갤러리 선확인·완료 기준은 사용자 작성안을 반영한 PORTFOLIO_GUIDE.md를 따른다. 역할명 나열 대신 실제 작업 사례, 결과물 선배치, 기존 서버 포트폴리오/PPT 외부 연결을 포함한다. 원본을 그대로 화면에 복제하거나 빈 회고를 추측으로 채우지 않는다.

2026-10-19 사용자 보정. 기준은 사이트 초안 PR30을 병합한 master146c4f1, 브랜치 codex/portfolio-site. 초안은 배포 연결 테스트용이며 새 방향을 만족한 것으로 취급하지 않는다.

목표: 제출용으로 AI 활용 개발 과정과 실제 결과물을 간결하게 둘러볼 수 있는 웹사이트. 홈/작업 목록/작업 상세/과정/날짜별 캡처를 링크 탐색한다. 현재 게임 화면은 중간 결과물이며 향후 개선 화면과 비교 가능해야 한다.

소유권: 구현 담당 site(media 제외)/tools/site/workflow/ignore, 문서 담당 SHOWCASE/portfolio 작업별MD, Coordinator 운영 지침·작업 카드·미디어·Git, 독립 리뷰 읽기·리뷰 문서. 게임/DB/Unity 변경 제외.

완료 조건: 긴 PPT형 단일 페이지 제거, 자연어 작업·문제 해결·결과의 짧은 본문, 실제 캡처와 보존된 화면 이력, 내부 ID/PR/승인/병합/검증 숫자 공개 비노출, 실제 링크 탐색/상대경로/모바일 통과. Pages는 PR build/artifact만, master deploy 유지. HTML은 MD에서 생성하고 공개 artifact에는 사이트 파일만 포함한다.

검증/비용/종료: 구현·내용·독립 리뷰 후 한번의 빌드/전체 내부 링크·미디어/배포 조건/zip 범위/1440·768·390 실제 브라우저 탐색 배치. 수정이 생기면 영향 검증만 다시 한다. 수분 내 완료하는 정적 사이트 검증이며 Unity 재실행은 하지 않는다. 통과하면 PR 전 미리보기를 제공하고 사용자 정책에 따라 Slack 최종 승인 요청. 초안 승인 WEB01을 새 개편안 승인으로 재사용하지 않는다.

# AI Agent 작업에서 느낀 점과 바꾼 방식

AI Agent와 3D Unity 클라이언트를 구현하며 요구 전달·실제 조작·방향 선택 방식을 조정한 경험입니다.

## 원하는 결과는 구체적으로 전달해야 했다

위치·크기·단축키처럼 당연하게 여긴 조건도 직접 요구에 담아야 결과에 반영됐습니다.

### 바꾼 방식

목표와 입력 뒤 기대 결과를 함께 정리하고, 서버 판정과 Unity 표현을 구분했습니다.

### 남은 점

세부 조건만으로 사용 경험이 완성되지는 않아 실제 조작과 피드백이 필요했습니다.

## 자동 검증과 실제 조작감은 달랐다

자동 검증은 정해진 동작을 확인했지만, 이동 보정이나 공격 타이밍의 불편은 실제 플레이에서 발견했습니다.

### 바꾼 방식

자동 동작 확인과 실제 조작감 평가는 구분해 기록했습니다.

### 남은 점

한 번의 실제 입력만으로 모든 지연·불편이 해결됐다고 볼 수는 없습니다.

## 기획·아트는 예시를 고르는 방식으로 구체화했다

정확한 색·배치·연출을 말로 명세하기 어려운 기획·아트는 예시를 비교해 선택했습니다.

### 실제 선택 사례

전투·마을·사냥터·UI 시안을 함께 비교했고, 사용자가 선택한 조합을 제작에 반영했습니다.

### 바꾼 방식

관련 선택안을 한 묶음으로 제시하고, 답변을 기다리는 동안 독립 작업을 이어갔습니다.

### 남은 점

시안은 방향 선택 자료이며, 실제 적용 화면과 구분해야 합니다.

## 작업 묶음과 검토 기준도 조정했다

작업 흐름이 끊기지 않도록 관련 기능을 함께 검토하고 통과한 검증은 반복하지 않게 조정했습니다. 리뷰 의견은 코드·기존 계약에 맞는지, 다음 수정자가 이해하기 쉬운지 확인했습니다.

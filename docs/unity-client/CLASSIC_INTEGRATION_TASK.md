로그인/선택/진입 분리, 방향키·ZXC·보간/예측, AI 템포, 기존4존 연결, 아이템5종과 스킬3종 그림, 하단HP/MP HUD·장비재질 및 새112 스폰 후보를 한 큰 묶음으로 전달한다. 앞서 보존한 거래소·콘텐츠 브랜치를 함께 통합했다.

마지막 한 접속의 실제 UI 입력에서 로그인·선택·입장/이동·해제/서버시전/I-B/채팅I-B가드/HP0차단/퇴장 확인. 아이템빈가방·시장실제30그림을 확인했지만 전체4존왕복·새112실행서버·비어있지 않은가방·실거래성공은미실행. CLASSIC_INPUT_RESULTS.txt에실패/보완·한계원문을남겼다. HUD직접영향기존1개PASS. 전체회귀나반복접속은추가하지않았다.

대표실제화면2종·표면개선초안과공개MD를갱신,site홈+6상세빌드와로컬브라우저대표페이지를확인했다. 원격게시/병합전이며게시승인은구체적로컬커밋기준으로한번만요청한다.

# 정통 판타지 클라이언트 통합 묶음

사용자 최신 지시: 관련 기능은 큰 PR로 합치고 작은 완료마다 멈추지 않는다. 게시 승인이 필요한 지점 전까지 로컬 구현을 계속한다.

## 범위와 소유권

- Coordinator: 미게시 거래소·콘텐츠 브랜치를 이동/AI 후보에 병합, 구역 전환 일반화, 통합·최소 검증·Git.
- map_compatibility: 좌표 호환성 분석과 고정 diff 독립 리뷰. 제품 파일 수정 없음.
- item_icon_ui: 포션 Sprite 연결, 이후 별도 진입 화면 코드. 씬/Editor 조작은 Coordinator만 한다.
- 원본 Game와 루트의 관계없는 변경은 보존한다. 실제 후보는 UnityClient/Builds/C10-Delivery/source의 codex/classic-mmorpg-motion이다.

## 결정

- Zone 폭만 100→200으로 변경하면 저장된 Zone 2 이상 좌표가 새 영역 밖으로 밀린다. 중첩 영역을 크게 늘리는 방안도 채택하지 않는다.
- 먼저 기존 서버의 1↔2↔3, 1↔4 연결을 모두 노출한다. 4개 구역의 좌표/Cell/DB는 유지하고 지면 장식만 구역 원점으로 옮긴다. 이는 전체 맵 기하 확대를 완료한 것이 아니다.
- 현재 실제5종 아이템마다 별도 원본 그림을 연결한다. 알 수 없는 ID는 명시적 기존 표기를 유지하며 임의 그림을 재사용하지 않는다.
- 로그인·선택·서버 진입 대기는 기존 실제 상태에 따라 분리한다. 가짜 진행률이나 서버 미지원 조작을 추가하지 않는다.

## 최소 검증

통합 diff 독립 리뷰 후 구역 경계, 포션 실제 Sprite/선택, 콘텐츠 정수 임계값 3개만 실행한다. 이미 통과한 이동·AI·거래소 전체 회귀는 반복하지 않는다. 다음 진입 화면은 완료 후 직접 영향 1개로 검증한다. 실제 입력은 최종 후보에서 로그인·선택·이동·스킬·I/B를 한 흐름으로 합친다. 다른 사용자 창이 보이면 입력을 보내지 않는다.

## 현재 결과

- 거래소 병합 7b8c118, 콘텐츠 병합 06652bf 로컬 보존. 콘텐츠 확장에도 정수 HP 임계값 검증을 유지했다.
- 구역 경계, 포션 UI, 콘텐츠 임계값 직접 3개 최종 PASS. 첫 복합 필터는 발견 0개로 미실행 처리 후 정확한 이름으로 각각 한 번 실행했다.
- 첫 통합 서버 빌드는 MonsterData.h의 UTF-8 BOM 누락으로 한글 주석을 잘못 해석해 실패했다. BOM 복원 후 실패한 빌드만 재시도하여 MainServer·UnitTests Release 빌드 exit 0을 확인했다. 기존 경고는 보존했다.
- 실제 Unity 창 대상으로 받은 캡처가 다른 브라우저/Slack 화면을 보여 활성화·마우스·키 입력은 보내지 않았다. 실제 입력 PASS로 간주하지 않는다.
- push/PR/실행 서버 교체/DB 직접 쓰기 없음. 다음 진입 화면 구현을 이어간다.

## 다음 배치: 시작 지역과 사냥 밀도

기존 5×5 Cell과 좌표·중앙 보스는 유지한다. 선택적인 일반/강한 몬스터 25칸 배열을 추가하고, 배열이 없으면 기존 공통 개수로 작동한다. 시작 남서 셀은 비우고 북동 방향으로 밀도를 늘린 후보는 일반94+강한17+보스1=112다. 이 방향을 모든 실제 배경의 숲 방향과 일치한다고 단정하지 않는다. 캐릭터 능력치·경제·DB·추적 Cell 이동은 변경하지 않는다.

후보 에셋은 백업 뒤 Unity API로 적용·export했고, 빈 배열의 기존241 보존과 새 배열/오류 거부를 직접 자동 시나리오1개로 검증해 통과했다. 완성 diff 독립 리뷰 차단0. 별도 Hunt-Layout 폴더의 서버·UnitTests Release 빌드 exit0, 실제 InitializeMonster를 호출한 native1개 PASS를 확인했다. 이미 통과한 AI/이동/거래소/진입 회귀는 반복하지 않는다. 현재 실행 서버22424에는 이 새 밀도를 아직 적용하지 않았다.

## 아이템 5종 연결 결과

HP·MP 포션, 철검·철방패·가죽갑옷 원본을 제작해 기존 카드/상세/거래소 행에 연결했다. 원본은1254px 그대로 보존하고 Unity Sprite 임포트는256px로 제한했다. 실제5개 Sprite의 로드·서로 다른 객체·상세/빈목록과 알 수 없는 ID fallback을 영향 시나리오1개에서 통과했다. 실서버 가방에 없는 아이템을 추가하거나 신규 장착/사용 기능을 만들지 않았다. 실제32/64px 비교와 비어 있지 않은 실서버 가방 촬영은 아직 수행하지 않았다. 이미지 생성은 이번4회/이전HP1회,재생성0이다. 금속·가죽 재질 원본2종을 생성해 기존3재질에 적용·동일camera 비교했고 제작도구의 재실행 유지도 보완했다. 다음은 실제입력과 다른 별도의 HUD 표현 저작이다.

# 내 매물 조회와 검색 전환

요약: 현재 캐릭터의 매물만 조회하고, 새로고침하거나 판매 검색으로 돌아갑니다.
상태: 검증된 결과

## 구현한 기능

- 판매 검색·내 매물 탭 전환
- 현재 캐릭터 소유 매물만 조회
- 내 매물 새로고침과 정상 빈 결과 표시
- 탭·접속·구역 전환 뒤 이전 응답 차단

## 현재 확인한 범위

두 캐릭터로 내 매물의 빈 결과와 판매 검색 복귀를 확인했습니다. 실제 소유 매물은 확인하지 않았으며 등록·구매·취소·수령은 지원하지 않습니다.

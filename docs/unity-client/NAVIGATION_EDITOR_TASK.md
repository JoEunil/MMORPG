## 이번 범위

기존 C20WorldMap 자산의 기본 Inspector가 250100바이트 배열을 그대로 노출하므로, 저장된 통행 격자를 읽는 UI Toolkit Inspector로 대체한다. 기존 원점·타일 크기·치수 필드는 유지하고 raw 배열 대신 통행/차단 색과 합계·경계 규약을 보여준다. 저장된 격자와 현재 Scene 장애물이 동기화됐다고 단정하지 않으며 geometry 변경 후 기존 bake/export가 필요함을 표시한다.

- navigation_preview_editor 소유: 신규 Editor/C20WorldMapInspector.cs와 meta만.
- Coordinator 소유: 최소 검증·ROOT 동기화·문서/공개 원본·Git 통합. Scene/기존 자산/서버 변경 없음.
- 독립 리뷰: 배열 방향·축/상한·미유효 데이터·큰 맵 메모리·임시 Texture 정리·기존 자산을 자동 변경하지 않는지 확인한다.
- 검증은 구현/리뷰 동결 후 유효 격자 표시/큰 맵 축소와 invalid/수명 정리의 직접 영향 두 시나리오로 제한한다. 필요 시 실제 데이터의 생성 preview PNG만 확인한다. 실제 게임 캡처나 Unity 입력 통과로 기록하지 않는다.
- 종료: 컴파일 오류0·독립 차단 없음·두 시나리오 통과·데이터/Scene 불변. 서버/로그인/사냥 전체 회귀는 재실행하지 않는다.

실제 밀도 조절·새 충돌 배치·A* 구현·AI 수정·서버 재시작은 포함하지 않는다. Unity 실입력 보류를 유지하고 새 기능은 다음 큰 관련 PR 게시 직전에만 Slack 승인을 요청한다.

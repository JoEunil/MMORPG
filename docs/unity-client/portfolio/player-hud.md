# 사냥 상태와 전투 HUD

상태: 중간 결과
요약: 서버의 성장 정보와 몬스터 체력을 전투 화면에서 확인합니다.

## 구현한 기능

캐릭터의 체력·마나·레벨·경험치를 표시합니다. 하단 HP·MP 게이지를 확대하고 세 스킬의 Z·X·C 키 표기를 키웠습니다. 몬스터의 체력 게이지는 서버 상태에 따라 갱신되며 사망·만료·로그아웃 뒤 정리됩니다.

## 현재 확인한 범위

실제 필드에서 Ring 스킬 사용과 마나 소모를 확인했습니다. 공격받은 몬스터 세 마리의 체력이 1,500에서 500으로 줄었고, 게이지도 3분의 1로 표시됐습니다. 퇴장하면 몬스터 게이지가 정리됩니다. 이번 실행에서는 몬스터 처치나 경험치 증가를 관찰하지 않았으며, 화면의 레벨 1·경험치 0은 진척 보상 결과가 아닙니다. Z·X·C 입력은 후속 실제 접속에서 서버 응답을 확인했습니다. 확대된 하단 HUD와 Global·Zone·Whisper 채팅 탭은 구현·코드 검증을 마쳤으며 새 실제 화면 확인은 남아 있습니다. 아래는 이전 HUD의 화면 기록입니다.

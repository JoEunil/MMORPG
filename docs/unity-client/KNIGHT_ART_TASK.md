# 기사 아트·게임 UI·스킬 연출

사용자 요청: 판타지 MMORPG 분위기로 진입 화면·기존 기사·UI 품질을 높이고, 횡베기/회전/전방 내려찍기와 동작에 맞는 이펙트를 만든다.

- 범위: 기존 Unity 정적 파츠·uGUI·서버 ActionResult 표현. 신규 리깅·기능/서버 판정·사용자 몬스터 AI 변경 제외.
- 소유권: 아트 담당은 기사 저작 도구, 구현 담당은 모션/전투 표현과 직접 영향 fixture, Coordinator는 기존 UI/Scene/Prefab/Shader 통합과 유일한 Editor 조작, 리뷰 담당은 읽기 전용 독립 검토.
- 완료: 기사 겹판/재질/목·다리 연결 보완, 기존 화면 참조 유지한 아트 스킨, 3슬롯별 준비/타격/회수와 검흔/파쇄, 실제 Editor 렌더와 출처/확인 범위가 다른 메뉴 삽화 구분.
- 검증 한도: 직접 영향 3개 detached 검사와 무입력 로그인 Play 1회. 렌더 후 변경한 geometry 관련 C05만 재확인. 서버·이동·과거 통과 전체 회귀를 반복하지 않는다.
- 결과: KNIGHT_ART_RESULTS.txt 및 공개 전투/진입 화면 기록. 실전 입력·Player 빌드/성능 확인은 미실행으로 남긴다.
- 전달: 큰 아트 PR 하나. 검토 가능한 로컬 후보/미디어/사이트 준비 후 새 Unity Coordinator Slack 부모 ART01에서 게시 승인, 이전 CLEAN01 등 승인 재사용 금지.

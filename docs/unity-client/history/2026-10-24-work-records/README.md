# 과거 작업·리뷰·검증 기록 — 2026-10-24 정리

PR51 병합까지 누적된 작업·검토·실행·요청·옛 인계를 모았다. **이 폴더는 실행 지침이나 현재 승인 대기열이 아니다.** 실패·미실행·보류도 원래 상태로 보존했으며, 폴더에 옮겼다는 이유로 모든 작업이 완료됐다는 뜻은 아니다. 옛 NEXT/HUNTING_BALANCE 등 후보의 수치와 계획은 현재 요구나 자동 재개 명령이 아니다.

현재 규칙은 [AGENTS](../../../../AGENTS.md), 현재 상태는 [HANDOFF](../../HANDOFF.md), 기술 계약은 [문서 안내](../../README.md)에서 확인한다. 이전 지침 감사 원문은 수정하지 않았다.

본문의 당시 판단·결과는 유지하고 위치 변경에 필요한 경로만 보정했다. 정리 전 Git 원본과 이동 후 파일의 해시는 [manifest](MANIFEST.txt)에 기록한다. 인계·진행 문서의 전체 이전 본문도 아래에 보존했다.

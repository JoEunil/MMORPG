# C06 — 서버 채팅 연결

목표: 기존 서버의 전체 채팅을 현재 ClientCore wire와 연결하고, Unity에서 실제 본인·타 플레이어 메시지를 표시한다. 서버 제품 수정은 이번 단위에 포함하지 않는다.

범위: ClientCore 채팅/profile24·25 파서와 요청·dispatcher/profilecache의 최소 호환 수정, 기존 Canvas에 최근12줄·입력·전송 패널, 의미 있는 패킷 회귀와 전용peer/native입력 배치. 로컬 성공 에코/새 채널/귓속말 UI/명령어/더미 플레이어/일반 프로필 프레임워크 제외.

소유권: c06_core가 ClientCore/새wire테스트/C06Peer와필요fake1줄호환, c06_ui가C06ChatScreen/최소Editor설치도구, root가현재씬설치·통합·새C06실입력helper·Git/기록. 동일파일동시편집금지. Editor조작root단독.

기대 결과: 현재wire에서오프셋·길이·개수·UTF8를검증해수신, 인증된지정계정1과2가고유본문을서버를거쳐주고받아표시. 이름은실프로필또는서버chatID fallback, TMP richText=false. 128 UTF8 byte/noNUL/empty전송거부, 입력초점중이동·키1/2/3스킬없음. 실패시입력보존/오류표시. 세션교체·비활성화시구독/임시입력정리.

비용/검증: 중간에는컴파일·정적리뷰만. 구현·독립리뷰·씬설치완료후고정버전에서 C06wire/profile회귀와직접영향C02/C04/C05회귀를한번, 한Play흐름에서peer계정2+native계정1입력·송수신·한도·초점차단·캡처를묶어실행. 실제입력상한120초/peer상한180초부터. HP0면새공격/이동유도없이채팅/종료관찰범위판단,DB주입금지. 동일원인수정2회한도. 통과후추가재실행없음.

종료 조건: 각예정검증결과와캡처확인, 정상disconnect/peerdispose/Playstop/selector·마우스·키보드·구독정리/Assets동결해제. 미실행·차단·실패·통과를구분한다. R01기존회귀를바꾼새서버빌드는아니므로CPP전체회귀/서버교체는없다. 기존서버Global key미초기화위험은별도분석이력으로보존하고실제실패면원인분리한다.

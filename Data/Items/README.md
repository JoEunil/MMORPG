# 아이템 데이터

UTF-8 CSV를 사용한다. `Potions.csv`, `Weapons.csv`, `Shields.csv`, `Armors.csv`를 모두 읽어 하나의 아이템 테이블로 구성한다.

- 첫 행은 필드 이름이다. 열 순서는 바꿀 수 있지만 필드 추가·누락과 중복 이름은 오류다.
- `itemID`는 네 파일 전체에서 중복되지 않는 양수다. 이름과 무게는 각각 비어 있지 않은 문자열과 양수다.
- `potionType`은 `0 = HP`, `1 = MP`다. enum 값을 바꿀 때는 데이터의 숫자 의미도 함께 확인한다.
- 쉼표·줄바꿈이 있는 문자열은 큰따옴표로 감싸고, 문자열 안의 큰따옴표는 `""`로 쓴다. UTF-8 BOM, CRLF와 LF를 지원한다.

최상위 `Data` 폴더가 데이터 정본이다. MainServer와 UnitTests 빌드 시 하위 CSV를 폴더 구조 그대로 실행 파일 옆의 `Data`로 자동 복사한다. 서버는 워커와 캐시 복구 시작 전에 데이터를 한 번 로드하며, 검증 실패 시 시작을 중단한다. 실행 중 재로드는 지원하지 않는다.

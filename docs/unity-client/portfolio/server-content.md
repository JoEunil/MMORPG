# 스킬·몬스터 데이터 편집

요약: Unity에서 스킬과 몬스터의 수치를 편집하고 서버가 사용하는 데이터로 내보냅니다.
상태: 검증된 결과

## 구현한 기능

Unity Inspector에서 Ring 스킬의 마나·재사용 대기·공격 범위와 일반 몬스터의 체력·공격력·이동 속도·보상을 편집합니다. 내보내기를 실행하면 서버의 기존 데이터 테이블에서 읽는 파일을 생성합니다. 잘못된 값은 내보내기 전에 차단합니다.

## 현재 확인한 범위

기존 수치를 그대로 내보내 C++로 컴파일하고, 스킬과 몬스터의 기본값이 유지되는 것을 확인했습니다. 같은 데이터를 다시 내보내도 결과가 같고, 검증에 실패하면 기존 출력 파일을 바꾸지 않습니다. 현재 실행 중인 서버에는 새 데이터를 배포하지 않았습니다. 편집 대상은 Ring 스킬과 일반 몬스터 한 종류입니다.

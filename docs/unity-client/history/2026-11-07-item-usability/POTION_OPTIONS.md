# 방어 장비 병합 후 등급 HP/MP 포션 선택안

## 묶음·개정·고정 조건

- 묶음: 방어 장비 PR71 병합 이후 진행할 등급 HP/MP 포션 정책 선택. 병합 여부는 실제 선택 전달 전에 Coordinator가 확인한다.
- 고정: HP포션 ID1 회복 1500, MP포션 ID2 회복 500, 양쪽 공유 쿨다운 120틱(6초), 숫자 퀵슬롯 1·2. 기존 효과·키를 재질문하지 않으며 등급 추가를 이유로 퀵슬롯 확장을 가정하지 않는다.
- 제외: 몬스터 AI, 처치 보상 포션, 드롭 테이블, DB 시딩/스키마 변경. 새 ID는 실DB 카탈로그와 ID33의 의미를 확인하기 전 정하거나 예약하지 않는다.
- 기존 플레이어 마켓은 플레이어가 이미 보유한 아이템을 거래하는 경로이므로 신규 포션의 최초 공급원이 될 수 없다. NPC 상점·제작은 현재 구현되어 있지 않다.

## 확인한 사실과 미확인

- canonical `CoreLib/ItemData.h`는 ID1 HP포션(1500 회복, 120틱), ID2 MP포션(500 회복, 120틱), ID3 철검, ID4 철방패, ID5 가죽갑옷을 정의한다. ID3~5는 PR71 장비 후보의 데이터다.
- `ARMOR_POTION_SCOPE.md`의 코드 경로 분석상 회복량·쿨다운 데이터와 일반 아이템 사용 요청은 재사용 가능하다. 현재 `InventoryScreen`은 사용 가능 아이템, 응답 문구, 숫자 퀵슬롯/수량을 ID1/2에 고정한다. `ItemPresentation`은 아이템 데이터 기반 이름/효과를 쓰지만 아이콘·badge·색은 기존 ID1~5에 한정한다.
- 등급 소비품을 늘리면 서버에 신규 정적 아이템 정의가 필요하고, Unity 가방 사용 허용·결과 문구·등급 아이콘/표시를 확장해야 한다. 기존 사용 요청 경로는 재사용 가능하므로 새 opcode나 인벤토리 저장 형식 변경은 필수로 확인되지 않았다.
- 공급원이 없는 등급 포션은 플레이 가능한 기능으로 완결되지 않는다. 신규 포션은 기존 플레이어 마켓에 먼저 공급되지 않으므로, 최초 획득 경로가 별도로 필요하다. ID33 및 실DB 전체 카탈로그의 충돌/예약 여부는 미확인이다.

## 추천 조합과 영향 작업

추천: **A를 선택해 현 상태를 유지하고 등급 추가를 보류**한다. 새 포션을 실제 획득 가능하게 만들려면 NPC 상점 같은 최초 공급원이 필요하지만, 현재는 미구현이므로 등급 아이템만 먼저 넣으면 플레이 흐름이 닫히지 않는다. B는 신규 골드 상점까지 포함한 더 큰 경제 기능으로 사용자가 명시적으로 선택할 경우 검토한다. 가격·회복 수치는 답변 없이 추정하지 않는다.

- B 선택 시 구현 범위 확정 전 확인: canonical 브랜치/PR71 병합 상태, 실DB 카탈로그와 ID33의 의미, 기존 골드·인벤토리 갱신 경로에서 구매를 원자적으로 처리할 수 있는 위치.
- B의 최소 구현 후보: 정본 ItemData에 선택된 등급별 회복량·기존 공유 쿨다운을 정의하고 JSON→Unity 전달을 유지, 서버 `UseItem`의 기존 경로 재사용, `InventoryScreen`의 ID1/2 고정을 데이터 기반 사용 가능 판정/결과 안내로 변경, `ItemPresentation`에 신규 등급 아이콘·badge·색 연결, NPC 구매 UI/요청과 서버 골드 차감·아이템 지급을 한 구매 흐름으로 구현한다. 구매는 원자적으로 처리하고 실패 시 골드/아이템 상태가 부분 반영되지 않게 하며, 재전송/중복 요청의 이중 차감·지급을 막아야 한다.
- 실제 DB 카탈로그와 ID33 의미 확인 후에만 신규 ID를 결정한다. 가격·회복량·구매 제한도 선택 전에는 정하지 않는다. B는 서버 경제 계약 및 구매 화면까지 포함하는 새 범위다.
- 회복량/부분 회복과 HP·MP 상한, 가격/비용, 등급별 구매·사용 제한은 미정 선택이다. 어떤 안도 DB 시딩/스키마 변경, 처치 보상, 드롭 테이블 또는 미확인 ID 예약을 승인하지 않는다.

## Coordinator 비동기 질문 초안

> PR71 병합 후 등급 HP/MP 포션은 **A) 현재 HP1500·MP500 두 종류를 유지하고 등급 추가를 보류**할까요, 아니면 **B) 낮은/높은 등급과 신규 골드 NPC 상점을 다음 주요 개발 묶음으로 선택**할까요? 신규 포션은 기존 플레이어 마켓에 공급 재고가 없으므로 마켓만으로 최초 획득 흐름을 만들 수 없습니다. B는 미구현 상점의 구매 UI와 서버 골드 차감·아이템 지급, 원자성·실패 처리·중복 요청 방지를 포함하는 더 큰 범위이며, 회복량·가격은 별도 선택이 필요합니다. ID33을 포함한 카탈로그 확인 뒤에만 새 ID를 정합니다. 어느 쪽도 DB 시딩/스키마 변경, 처치 지급, 드롭 테이블 변경을 승인하지 않습니다.

질문은 Coordinator가 지정한 현재 비동기 경로로 한 번 전달한다. 미응답은 선택으로 처리하지 않는다.

# 캐릭터와 함께 필드를 오가는 과정

요약: 캐릭터로 필드에 진입해 서버 상태에 맞춰 인접 구역을 오갑니다.

상태: 검증된 결과

## 구현한 기능

- 로그인 후 서버에서 받은 캐릭터를 선택해 월드에 진입합니다.
- 쿼터뷰 필드에서 마우스로 캐릭터를 이동하고 서버가 확인한 위치를 반영합니다.
- 인접 구역으로 이동하면 새 구역의 캐릭터와 월드 상태를 표시합니다.
- 구역을 바꾸는 동안 이동·스킬 입력을 잠그고, 새 구역의 본인 상태를 받은 뒤 다시 조작할 수 있게 합니다.

## 현재 확인한 범위

실제 로그인과 캐릭터 선택부터 두 구역을 오가는 흐름을 확인했습니다. 구역을 이동한 뒤 서버 위치와 캐릭터 표시가 일치하는지 검증했습니다.

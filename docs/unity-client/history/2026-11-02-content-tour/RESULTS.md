# 콘텐츠 둘러보기와 공개 페이지 정리 — 2026-11-02

## 촬영 범위

실제 로컬 서버에 접속한 Unity 게임 화면을 촬영했다. Z 기본 베기, X 회전 베기, C 전방 내려찍기, 거래소 조회·판매 등록, 등록 취소, 전체·구역·귓속말 채팅의 8개 GIF와 정지 포스터를 만들었다. 원본 프레임의 시간 순서는 유지하고 공간 크롭·확대만 적용했다. 공개 미디어 메타데이터는 `site/media/releases/2026-11-02/content-tour-media.json`이다.

스킬 버튼 클릭 뒤 MP 감소를 관찰했고 C 공격으로 몬스터 처치·EXP 160→170을 확인했다. HP 포션 1개를 100다이아에 등록해 수수료 10골드 차감과 내 매물을 확인했다. 이후 정상 취소·아이템 회수를 확인했으나 취소 GIF는 취소 응답까지만 포함하므로 수령 완료 장면으로 설명하지 않는다. 거래 취소로 이미 차감된 등록 수수료는 복원되지 않았다. DB 직접 수정은 없었다.

전체 채팅은 두 캐릭터의 송수신, 구역 채팅은 전송·자기 응답, 귓속말은 지정 대상에게 전송·상대 답장을 관찰했다. 첫 귓속말 take는 촬영 종료 후 전송되어 증거에서 제외했다. 사용자 재로그인 후 재촬영한 `chat-whisper-final/0062.png`에서 보낸 문장과 실제 상대 답장을 확인한 뒤 종료했다. 키보드 입력 성공을 이 촬영으로 주장하지 않는다.

## 검증과 검수

8개 GIF·8개 포스터와 연결 경로를 필수로 검사하는 `tools/site/build.py --require-tour-media` 빌드를 통과했다. 데스크톱 1265px·모바일 override 390px(본문 375px)에서 가로 넘침이 없고 제목·섹션 탐색·본문을 읽을 수 있음을 확인했다. GIF 펼침·실제 이미지 로드·원본 링크를 확인했다. 작은 모바일 화면의 세부 게임 글자는 원본 확대 링크로 확인할 수 있다. 실제 모바일 기기·느린 네트워크의 성능 측정은 하지 않았다.

종합 검수 담당은 최초 완성 후보를 필수 수정 없이 통과시켰다. 추가 피드백으로 날짜—핵심 한 줄 이력과 기능 상세 내 펼침을 적용하고 홈→기능 상세→원본 최대3단계 경로를 검사했다. 예전 history.html 주소를 유지했다. Agent 관계도에 선택적 병렬 배정과 같은 담당자로 돌아가는 피드백을 표시했다. 내부 원문과 공개 이력의 이미지 참조128개를 대조해 누락0을 확인했다. 같은 종합 검수 담당이 최종 관계도·이력의 데스크톱·모바일 캡처를 확인해 통합 후보 통과/필수0으로 판정했다. 실제 최종 실행 지표553회를 반영한 빌드도 통과했다.

## 종료와 보존

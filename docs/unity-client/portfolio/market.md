# 거래소

요약: 매물을 조회하고, 판매·구매와 내 매물 관리를 확인하는 거래소 화면입니다.
상태: 중간 결과

## 대표 화면

![거래 아이템 수령함에서 빈 목록과 전체 수령 응답을 확인한 실제 게임 화면](../../../site/media/releases/2026-11-06/trade-item-receipts.jpg)

구매품·취소 반환품을 모아 확인하는 수령함입니다. 화면은 수령 대기 항목이 없는 실제 서버 상태입니다.

## 구현한 기능

- 종류·페이지별 매물 조회와 선택 상세
- 매물 검색·내 매물·판매 등록·거래 아이템 수령함
- 구매·판매 취소·아이템 반환·대금 수령
- 구매품·취소 반환품 목록과 전체 수령
- 수령 준비·처리 중 구분, 수령 후 가방 갱신
- 아이템 수량·묶음 가격 입력과 등록 전 골드 수수료
- 골드·다이아 잔액과 거래 뒤 갱신
- 불확실한 거래 결과 보존과 자동 재요청 차단
- B 키 열기·닫기와 가방·거래소 상호 배타 표시

## 현재 확인한 범위

실제 서버에서 빈 목록·0건 수령·목록 재조회를 확인했습니다. 항목이 있는 수령과 창을 닫은 뒤 결과 반영은 자동 검사로 확인했습니다.


| 실제 확인 (2026-11-02) | 결과 |
| --- | --- |
| HP 포션 1개를 100다이아에 등록 | 내 매물에 표시 |
| 등록 수수료 10골드 | 등록 시 차감 |
| 등록 취소와 아이템 반환 | 취소 응답과 반환을 별도로 확인 |

제약: GIF는 취소 응답까지만 담았으며, 다양한 거래 조건은 미확인이고 등록 수수료는 취소 후에도 복원되지 않습니다.

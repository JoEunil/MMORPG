# 현재 인계 — 월드 지형·스폰

- PR [#76](https://github.com/JoEunil/MMORPG/pull/76)은 지도 성곽·통로 및 필드 길안내를 게시한 상태다. 추가 후보는 이 PR 헤드를 기반으로 한 정본 작업 폴더의 `codex/zone2-terrain-spawns`다.
- Zone 2 단독 후보 `bea9319`는 새 서버에서 지도 목적지 선택, 필드 화살표·거리, 사용자 이동과 도착 자동 종료를 확인했다. 검증 실행 묶음은 정상 종료했다. 내부 근거는 `Builds/Zone2Terrain`에 보관한다.
- 사용자가 PR #76에 Zone 2 추가를 승인한 뒤 나머지 구역으로 확대를 지시했다. Slack의 기존 `ZONE2ROUTE01` 요청은 단독 후보를 대상으로 했으며, 전체 후보와 구분한다.
- 확대 후보는 Zone 2~6 지형·초기 스폰, 인접 구역 연결 통로 및 지도 목적지로 구성한다. 기존 마을·성곽, 구역별 몬스터 수·보스 위치와 몬스터 AI를 유지한다. 자세한 설계는 [BRIEF](BRIEF.md#후속-레벨-디자인--사냥터-지형과-통로).
- Unity와 서버에 같은 통행 데이터를 내보낸다. 최신 확대 후보의 검증 근거는 `Builds/WorldZoneLayout`에 보관한다. 테스트 계정 로그인은 허용된 도구 범위에서 총괄이 처리한다.
- 확대 후보는 Unity 씬에서 구역 간 통로 7곳, 내부 통로 10곳, 마을 출발 경로 5개, 두 보스 좌표를 확인했다. 양쪽 통행 격자 250,100타일 일치, Windows·MainServer 빌드, Unity 스폰 1건·서버 스폰 1건·구역 전환 회귀 5건 통과. 검증 서버·로그인·게임 정상 기동과 종료 확인. 확대 후보의 사용자 실이동은 미실행이며, Zone 2 단독 후보의 실이동 결과와 구분한다.
- 종합 검수에서 길 폭 문제를 발견해 수정했고, 새 atlas와 경계·통로를 재검수해 통과했다. 사용자 채팅의 기존 PR 추가 게시 지시와 전체 구역 확대 지시를 이 후보에 적용한다.

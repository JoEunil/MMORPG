# 스킬·몬스터·맵 편집

요약: Unity의 스킬·몬스터 설정과 맵의 통행 데이터를 서버에 연결합니다.
상태: 검증된 결과

## 구현한 기능

Unity Inspector에서 기본 공격·범위 공격·보스 공격의 마나·재사용 대기·공격 범위와 몬스터의 체력·공격력·이동 속도·보상을 편집합니다. 보스의 체력 단계별 스킬 순서와 대기 시간도 기존 패턴 안에서 조정할 수 있습니다. 내보내기를 실행하면 서버의 기존 데이터 테이블에서 읽는 파일을 생성합니다. 잘못된 값은 내보내기 전에 차단합니다.

## 몬스터 배치 편집

셀마다 생성할 일반·강한 몬스터 수와 가장자리 시작 간격을 편집합니다. 격자 미리보기에서 셀별 개수와 구역 합계를 바로 확인할 수 있고, 중앙 보스는 별도로 표시합니다. 미리보기는 배치 규칙을 보여주며 실제 몬스터의 무작위 위치를 나타내지는 않습니다.

## 맵의 통행·충돌 편집

고정된 지면과 충돌시킬 오브젝트를 Unity에서 지정하고, 통행 가능한 위치를 작은 격자로 내보냅니다. 서버와 클라이언트가 같은 데이터를 읽으며 이동 경로에 벽이 있거나 대각 모서리를 끼고 통과하려 하면 막습니다. 주변 객체를 관리하는 큰 Cell과 길찾기에 사용할 작은 격자는 구분합니다.

맵 내보내기와 서버 빌드, 자동 충돌 검증을 확인했습니다. 실행 중인 서버에는 아직 적용하지 않았고 실제 이동 입력 검증도 보류 중입니다. 몬스터 A*는 이 격자를 사용할 연결 지점만 마련했으며 경로 탐색을 완성한 것은 아닙니다.

## 현재 확인한 범위

새 배치 후보는 시작 셀을 비우고 멀어질수록 적이 늘어나도록 구성했습니다. 내보내기와 서버 초기화에서 총 112마리 배치를 확인하고 테스트 서버에 반영했습니다. 생존 상태의 사냥 동선과 난이도 확인은 남아 있습니다.

전체 스킬·몬스터 수치를 내보내 C++로 컴파일하고, 기존 테이블의 모든 수치·공격 단계·보상과 같은지 대조했습니다. 실제 스폰 초기화 함수에서도 기존 241마리의 종류·순서·배치 범위를 확인했습니다. 편집 화면에서 몬스터 수를 바꾸면 합계가 갱신되고 기본값으로 복원되는 것도 확인했습니다. 잘못된 값은 기존 출력 파일을 바꾸지 않습니다.

수치 편집은 현재 서버의 스킬 다섯 종류와 몬스터 세 종류를 지원합니다. 기존 에셋의 편집값은 보존하면서 범위를 넓혔습니다. 스폰 설정은 기존 셀 구조와 중앙 보스 배치를 유지합니다. 편집값은 서버 빌드에 포함될 때 적용되며, 편집만으로 실행 중인 서버가 바뀌지는 않습니다.

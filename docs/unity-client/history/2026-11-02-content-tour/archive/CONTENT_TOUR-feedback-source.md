# 클라이언트 콘텐츠 둘러보기

스킬·거래소·채팅이 실제 게임에서 동작하는 모습을 둘러보세요.

## 세 가지 스킬

Z·X·C 키로 서로 다른 공격을 사용합니다. 준비 중 공격 영역과 발동 동작을 표시하고, 하단에서 마나와 재사용 대기 시간을 확인합니다.

### Z — 기본 베기

Z 스킬 아이콘을 클릭해 기본 베기를 사용하고 마나가 줄어드는 것을 확인했습니다.

영상: ![기본 베기의 준비와 발동](../../site/media/releases/2026-11-02/skill-strike.gif)

### X — 회전 베기

X 스킬 아이콘을 클릭하면 캐릭터 주변에 넓은 원형 준비 영역이 나타나고 회전 공격으로 이어집니다.

영상: ![회전 베기의 전신 회전과 자세 회복](../../site/media/releases/2026-11-02/skill-sweep.gif)

### C — 전방 내려찍기

C 스킬 아이콘을 클릭하면 전방 준비 영역과 공격이 이어지고, 몬스터를 쓰러뜨린 뒤 경험치가 늘어납니다.

영상: ![전방 내려찍기의 준비 영역과 참격](../../site/media/releases/2026-11-02/skill-cleave.gif)

실제 게임에서 마우스로 스킬을 클릭한 화면을 공격 영역과 하단 상태가 함께 보이도록 확대했습니다.

[전투·상태 UI의 확인 범위와 화면 이력](/MMORPG/work/player-hud/)

## 거래소 둘러보기와 판매 등록

거래소 버튼을 클릭해 매물을 조회한 뒤 HP 포션 1개를 100다이아에 판매 등록하고, 내 매물에 표시되는 것을 확인했습니다.

영상: ![거래소 매물 조회와 판매 등록 화면 흐름](../../site/media/releases/2026-11-02/market-flow.gif)

등록 전 수량·묶음 가격과 골드 수수료를 확인하고, 확인 버튼으로 판매를 확정합니다.

### 내 매물에서 등록 취소

내 매물을 선택해 취소 버튼과 확인 버튼을 누르면 취소 완료 안내가 나타납니다.

영상: ![등록한 포션을 선택해 판매를 취소하는 실제 거래소 화면](../../site/media/releases/2026-11-02/market-return.gif)

실제 게임의 조회·등록·취소 화면을 거래소 패널 중심으로 확대했습니다.

[거래소 기능과 실제 거래 확인 범위](/MMORPG/work/market/)

## 전체·구역·귓속말 채팅

채팅 탭으로 대화 범위를 고르고 메시지를 입력해 전송합니다. 받은 메시지는 채널을 구분해 최근 대화에 표시합니다.

### 전체 채팅

전체 탭에서 인사말을 입력하고 보내기를 누르면 대화에 표시되고, 다른 캐릭터의 답장이 도착합니다.

영상: ![전체 채팅 메시지를 보내고 다른 캐릭터의 답장을 받는 실제 화면](../../site/media/releases/2026-11-02/chat-global-zone.gif)

### 구역 채팅

구역 탭을 선택해 함께 사냥하자는 메시지를 보내면 구역 대화로 표시됩니다.

영상: ![구역 채널을 선택해 메시지를 전송하는 실제 채팅 화면](../../site/media/releases/2026-11-02/chat-zone.gif)

### 귓속말

받는 캐릭터를 지정해 준비한 메시지를 보내기 버튼으로 전송하면 내 귓속말과 상대 캐릭터의 답장이 대화에 표시됩니다.

영상: ![받는 캐릭터를 지정해 보내는 귓속말 채팅](../../site/media/releases/2026-11-02/chat-whisper.gif)

세 채널 모두 실제 게임의 메시지 전송과 서버 응답이 보이도록 채팅창을 확대했습니다.

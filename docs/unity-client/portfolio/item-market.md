# 아이템과 거래소 화면

요약: 인벤토리와 거래소 매물을 화면에 표시하고, 내 매물의 서버 수령 결과를 확인할 수 있도록 연결 중입니다.
상태: 중간 결과

## 구현한 기능

- 인벤토리: 아이템 이름·수량을 카드로 표시하고, 선택하면 슬롯과 수량을 상세 영역에 표시합니다.
- 거래소: 아이템 종류와 페이지로 매물을 조회하고, 목록에서 수량·가격·판매 상태를 확인합니다. 매물을 선택하면 판매자와 등록 정보를 보여줍니다.
- 내 매물: 현재 캐릭터의 매물만 따로 조회하고 새로고침하거나 판매 검색으로 돌아갑니다.
- 대금 수령: 판매된 내 매물을 선택해 수령 요청을 보내고 서버 결과를 표시합니다. 응답이 확인되지 않으면 완료 처리나 자동 재요청을 하지 않습니다.
- 화면 전환: 가방과 거래소 중 하나만 열리며, 창을 조작하는 동안 이동·스킬 입력이 필드로 전달되지 않도록 처리합니다.

## 현재 확인한 범위

거래소 목록·선택 상세·스크롤, 내 매물의 빈 결과와 대금 수령 불가 상태를 실제 서버에서 확인했습니다. 지정 계정에 수령 가능한 매물이 없어 실서버 지급 성공은 확인하지 않았으며, 지급 성공 경로는 테스트 응답으로만 확인했습니다. 인벤토리는 첫 조회 뒤 새로고침하자 서버가 빈 목록을 정상 반환했고, 화면에 “No items”가 표시됐습니다. 실제 아이템이 있는 목록과 카드는 테스트 데이터로만 확인했습니다. 아이템 사용·장착과 거래 등록·구매는 지원하지 않습니다.

# 구역별 몬스터 배치 편집

PR43 게시 후 독립 로컬 후속 브랜치 codex/zone-spawn-authoring에서 진행한다. 사용자가 수정할 A*·어그로·몬스터 Cell 이동은 건드리지 않는다. 실제 배치 밀도/스탯/보상은 유지하며 구역별 밀도를 기존 Unity 편집에서 조정할 수 있는 최소 연결만 추가한다.

- C15 선택 int[6] 밀도: 비었으면100%, 설정 시50~200%. 기존25셀·종류별 개수를 백분율 적용해 정수 내림, 중앙 보스1고정.
- 서버는 해당 구역의 밀도만 사용하고 구역별 최대1000을 컴파일에서 확인한다. 공통25셀과 실제 asset 값은 유지한다.
- 구현 소유권: zone_spawn_authoring은 C15 데이터/Exporter/Inspector/기존 C15Tests 네 파일, Coordinator는 서버 초기화·기존 SpawnLayout fixture와 문서/통합, zone_spawn_review는 읽기 전용 독립 리뷰다.
- 검증: 구현/리뷰 동결 뒤 C15 기존 자동 시나리오2개와 native 초기화 fixture1개만 한 배치로 확인한다. 6구역 기본112·모든 참조/좌표/통행/보스, null/100% 보존·혼합 밀도 계산·잘못된 값/교체 실패의 출력 보존을 확인한다. 새 입력·난이도 실측·서버 재기동은 제외한다.
- 종료 조건: 독립 P1/P2 없음, 직접 영향 빌드/자동검증 통과, 실제 입력 미실행 구분. 이미 통과한 월드/사냥 전체 회귀는 반복하지 않는다.

게임 내 결과 화면은 바뀌지 않고 편집 기능만 추가하므로 공개 페이지는 배치 편집 설명을 갱신한다. 실제 Inspector 캡처가 없으면 새 화면을 만들어낸 것처럼 게시하지 않는다. 다음 큰 관련 PR까지 로컬 후속으로 모으고 PR43에는 승인 범위를 벗어난 변경을 덧붙이지 않는다.

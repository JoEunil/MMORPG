# 몬스터 없는 마을과 사망 귀환

2026-10-22 사용자 요청: 기존 6구역 중 한 구역을 몬스터 없는 마을로 두고 부활 지점으로 사용한다.

- Zone 1 전체를 마을로 지정한다. 일반·강화·보스 생성 모두 0이며 나머지 5구역의 112마리 배치는 유지한다.
- 사망 화면의 Return to Town을 누르면 서버가 HP0·캐릭터 소유권·epoch·안전 좌표를 검사한다. Zone 1 (10,10)으로 이동하고 최대 HP/MP를 회복한다. 경험치·아이템·재화는 변경하지 않는다.
- 재로그인만으로 회복하지 않는다. 별도 DB HP 복구 요청 MAPHP01은 취소했고 직접 DB 수정은 하지 않는다.
- 신규 요청 opcode 39와 기존 구역 ACK/첫 Full 쌍을 사용한다. 서버·ClientCore DLL을 같은 버전으로 배포해야 한다. UI는 요청 직후 임의로 HP를 바꾸지 않는다.
- 몬스터 AI/A*·Cell 간 이동 제한·기존 사용자 WIP는 변경하지 않는다. 새 마을 아트나 NPC 기능은 이번 완료 범위가 아니다.

소유권: town_respawn_server는 서버/ClientCore/네이티브 테스트, Coordinator는 스폰 생성 정책·Unity 화면·기존 테스트 어댑터·DLL·문서, town_respawn_review는 읽기 전용 독립 검토. Editor 조작은 Coordinator만 한다.

검증은 동결 후 기존 Unity fixture 2개(스폰과 패배 화면), 네이티브 핵심 2개(부활·보존과 거부·중복 응답)만 실행한다. ClientCore/MainServer 빌드와 컴파일을 확인한다. 새 서버 정상 전환이 가능하면 실제 HP0 로그인→마을 귀환→회복/안전 지역 표시→정상 퇴장 한 접속으로 확인한다. 기존 전체 회귀는 반복하지 않는다.

로컬 후보 검증 뒤 TOWN01로 PR 게시 직전 Slack 승인을 요청한다. 기존 MAP01 승인은 재사용하지 않는다. 롤백은 새 서버 정상 종료 확인 후 기존 서버/DLL 쌍으로 복귀하며 강제 종료·DB 초기화는 하지 않는다.

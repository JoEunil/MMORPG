범위
- 기존 기사 파츠/피벗 유지: 닫힌 판금, 흉갑 능선, 겹판, 문장, 검 홈/가드, 목·다리·부츠 보호구와 brushed steel/가죽/붉은 천. 진입 디오라마에만 보조 Point 조명 2개.
- 기존 uGUI 컨트롤/직렬화 참조 유지: 성채 배경 삽화, nine-slice 금속 프레임/가죽 바탕, HP/MP 확대, Z/X/C, 채팅과 겹침 축소, 가방/거래소 외곽 스킨. 기존 선택/진입 책임 재사용.
- 서버 ActionResult의 phase 좌표/방향에만 준비·횡베기·회전·내려찍기 및 검흔·수직 참격·지면 파쇄 표시. 관찰 플레이어도 같은 슬롯 전달. 서버/AI/프로토콜/이동/판정/수치 변경 없음.
- 실체 없는 프레임워크/Manager/리깅/유료 에셋 추가 없음. Editor 도구 2개와 필요한 원본 shader/자산만 추가.

검증
Unity 6000.0.47f1 ROOT Editor 컴파일 오류/경고 0, custom vertex-color shader 오류 false.
독립 리뷰: Ring 종료 팔 튐/ParticleSystem duration 설정 전 정지/URP Unlit 정점색 미지원 P2 3건 수정. 최종 정적 P1/P2 없음.
직접 영향 3개 detached component 검사 PASS: C05 세션·해제·쿨타임/4방향 phase 좌표, C19 실제 prefab의 3슬롯 준비·해제·회수/권위 root 불변. 첫 실행 84/6/7ms.
렌더 후 geometry를 올리고 평면 범위를 보존하도록 수정. 두 기존 검사의 3D 거리/방향·이전 .96 반경 가정이 실패한 기록을 보존하고 planar X/Z와 실제 sweep layer 기준으로 수정. 해당 C05 2개만 재확인 PASS, C19·과거 서버/이동/로그인 검사는 반복하지 않음.
Play 1회 무입력 로그인 화면 확인. 처음 CLI의 구버전 명령 호환 오류로 Error Pause 발생해 wait_for timedOut. 실제 paused 상태 확인 후 재개하고 frameCount3414→3451 /105ms /framesObserved2 확인, 새 제품 오류 없음. 입력·서버 접속·실전 피해 검증 없음.
최종 Play=false/dirty=false/background=false 복구. 자산 저작은 Play/검사 동안 중단.

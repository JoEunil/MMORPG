# 플레이 HUD·가방 조회 확인 묶음

목표: 실제 플레이 화면의 체력·마나·스킬 조작 영역을 간결하게 정리하고, 가방 조회 실패 원인을 분리해 정상 조회 조건을 확인한다. 공개 기능 설명 갱신ef03b18은3f751bd로먼저통합했다. 사용자 기능 묶음 하나의 PR로 전달하며 원본root와Game WIP는보존한다.

포함: C05 기존 Full HP/MP의 읽기 쉬운 게이지·정확한 수치, 기존3스킬/방향/HP0·transition·로그아웃·가방/거래소/채팅 키차단 유지, 기존 Scene 대상 Editor Setup의 제한된 배치. 가방의 기존 서버/DB 실패 원인 분석과 승인 범위 안의 정상 조회 검증, 최종 공개 설명과 실제 캡처.

제외: 레벨업/경험치 규칙·가짜 수치/쿨다운·새 스킬·아이템사용/장착·거래·스키마·직접DB쓰기·서버큐/락/캐시 의미 변경·추상화 프레임워크. DB누락은빈성공으로덮지않는다. 데이터 보완이 필요하면 정확한 후보와 복구/검증을 준비해 지정Slack앱승인뒤에만실행한다.

소유권: HUD 담당은 C05CombatScreen.cs, 신규 Editor/C12HudSetup.cs(.meta), 신규 Tests/C02/C12HudTests.cs(.meta)만 저작한다. Scene/Editor조작/원본C02SceneBuilder/C02WorldScreen과통합/사이트는Coordinator. 서버분석은 NEXT_ITEM_CONTRACT.md만. 독립리뷰후소스/Assets/Packages/ProjectSettings동결하고한묶음검증.

완료조건: Full의현재/최대HPMP가게이지와수치에동일하게반영,최대0등불완전상태게이지안전/HP0정지,세스킬과방향/기존입력guard보존. 1280x720게임뷰에서HUD/채팅/가방/시장/Zone버튼겹침없음. DB정상가방성공은실제응답근거가있을때만완료,없으면미실행과승인경계를명시.

검증계획(최신축소): 완료한 HUD 자동/실입력은 재실행하지 않는다. BAG01 승인 후 DB 조건·반영 결과는 각 필수 가드와 READ ONLY로 확인하고, 실입력은 캐릭터5011의 로그인→가방→cold 실패일 때 Refresh 한 번→빈 성공→닫기/정상퇴장 한 흐름만 남긴다. 기존 시장/탭4응답·두계정 왕복·HUD전투 재실행은 제외한다. 두 빈 DB 행은 SELECT로 함께 확인한다. 대표 빈가방 캡처1장만추가한다. 성공이안되면반복하지않고원인을분리한다. 이번보완은서버제품/프로토콜변경이없어C02전체103개·C++전체·사이트전체검사를다시돌리지않는다. 사이트공개문구수정은변경본문/링크만확인한다.

# 거래소 구매와 구매품 수령 — 검증 결과

## 계획과 범위

판매 목록에서 매물을 선택하고 가격을 확인한 뒤 구매를 요청하고, 구매품은 별도의 수령 요청으로 가방에 반영하는 흐름을 구현했다. 기존 서버의 구매 트랜잭션과 구매품 대기열을 연결하며 DB 스키마·프로시저와 경제 규칙은 변경하지 않는다.

## 완료한 변경

- 선택한 매물 가격을 먼저 확인하고 다시 눌러야 구매 요청을 보내도록 했다. 처리 중에는 매물 선택과 중복 요청을 막는다.
- 서버 구매 결과와 구매품 수령을 별도 동작으로 표시한다. 결과가 불명확할 때는 자동 재구매하지 않는다.
- 명시적인 구매품 수령 뒤 기존 인벤토리 조회를 다시 요청한다. 오래된 가방 응답과 수령 뒤 새 조회가 겹치면 오래된 결과를 화면에 적용하지 않는다.
- 서버·ClientCore·Unity UI가 요청 식별자와 기존 캐릭터 세션 경계를 사용한다. 기존 구매/배송 절차를 연결했으며 DB 구조·절차는 바꾸지 않았다.

## 검증과 실제 실행 결과

독립 리뷰에서 차단 문제는 남지 않았다. Release `ClientCore`, `MainServer`, `UnitTests` 빌드가 통과했고, Unity 관련 자동 검증은 두 항목 통과 후 UI 검증의 잘못된 매물번호 기대를 실제 가격 확인 동작에 맞춰 고쳐 해당 항목만 다시 실행해 통과했다. 독립 C++ 검증 두 항목도 통과했다. 최초 실패와 수정 후 실행 기록은 공유 작업 폴더 `UnityClient/Captures/market-purchase-tests-final.txt`, `market-purchase-ui-rerun-final.txt`, `market-purchase-native.txt`에 보존했다.

실제 서버에서는 기존 매물 하나를 선택해 가격 확인 뒤 구매를 요청했다. 캐릭터에 다이아 보유 행이 없어 서버가 부족 상태로 응답했고, 사용 금액은 0이었다. 이어 별도로 구매품 수령을 요청했으며 이번에는 수령·중복·보류 항목이 모두 0이었다. 첫 가방 요청은 준비된 캐시가 없어 실패 상태였고, 가방을 다시 열어 서버를 재조회한 뒤 `No items`를 확인했다. 실제 구매·재화 차감·아이템 배송이나 지급의 영속화는 확인하지 않았다.

읽기 전용 전후 비교에서 두 테스트 캐릭터의 다이아 보유 행과 구매품 대기열은 모두 없었고 상태 변화도 없었다. DB 데이터 주입·초기화와 스키마/프로시저 수정은 하지 않았다. 실제 입력 요약과 전후 비교는 공유 작업 폴더 `UnityClient/Captures/market-purchase-live.txt`, `market-purchase-bag-after-receipt.txt`, `market-purchase-db-before.txt`, `market-purchase-db-after.txt`에 있다.

정상 종료 신호 뒤 서버 종료와 포트 해제는 확인했다. 보존된 종료 로그에는 정지 기록이 있으나 PowerShell 도구가 종료 코드를 전달하지 않아 숫자 종료 코드 0은 확인되지 않았다. error.log에는 기존 종료 경고 `CancelIoEx 1168` 한 건만 있었고, 새 후보 서버는 별도로 준비 완료 응답과 포트를 확인했다. 확인 스크립트의 한글 인코딩 문제는 결과를 수동으로 대조해 검증했으며 강제 종료나 DB 변경은 없었다. 이 운영 확인은 게임 기능 성공의 근거로 사용하지 않는다.

## 캡처와 전달 상태

실제 캡처는 가격을 확인하는 구매 확인 화면과 구매품 수령 뒤 빈 가방 화면이다. 원본은 `UnityClient/Captures/market-purchase-confirm.png`, `UnityClient/Captures/market-purchase-bag.png`이며 공개용 복사본을 `site/media/releases/2026-10-20/`에 추가했다. 공개 원본에서 HTML을 생성했고, 실제 브라우저에서 작업 상세와 화면 이력의 탐색, 이미지 7장 로딩, 폭 713/375의 가로 넘침 없음과 캡처 가독성을 확인했다. 상세 링크로 쓸 수 없는 상대경로는 공개 본문에서 제거했으며 전체 게임 검증은 반복하지 않았다. 미리보기는 http://127.0.0.1:8790/MMORPG/work/item-market/index.html 이고 정식 게시 전이다.

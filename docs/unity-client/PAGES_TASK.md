# P01 — AI-AGENT 소개 사이트와 지속 갱신

기준: master 1e36645060947fadbc1b278b1f9b9ccf2153fe61. 전용 브랜치 `codex/ai-agent-site`. C08/C09는 검증된 PR29의 결과로 소개하며 master 병합 완료로 표시하지 않는다.

- 목표: AI 활용 배경·역할 흐름·현재 구현·실제 화면·검증과 남은 범위를 한국어 사이트로 공개한다.
- 범위: SHOWCASE 원본, 템플릿/변환기/CSS, 선별 media, Pages Actions, 로컬 미리보기, 지속 갱신 지침. 게임·서버·DB·Unity 에셋 변경 제외.
- 소유권: 구현 담당은 site(media 제외)/빌드·검사·미리보기/workflow/ignore, 문서 담당은 SHOWCASE, Coordinator는 media·작업 카드·운영 지침·Git 통합, 리뷰 담당은 읽기 검토.
- 검증: 구현/리뷰 완료 뒤 빌드·링크/미디어·artifact 범위·master 전용 배포조건·데스크톱/모바일 실제 브라우저를 한 묶음으로 확인. 성공 후 새 수정 없으면 반복하지 않는다. 게임 입력 테스트는 이번 사이트 검증에 포함하지 않는다.
- PR 전 제공: 로컬 HTTP 미리보기와 화면 캡처, 배포할 정적 파일 zip. 외부 미리보기 공개는 실제 배포 이후와 구분한다.
- 게시: 사용자가 기본 주소와 첫 Pages 게시를 요청했고 Source=GitHub Actions를 설정했다. PR 직전 Slack 최종 승인 절차 유지. feature PR은 검증/artifact만 만들고 공개 배포하지 않는다. 사이트 PR의 master 반영 후 Pages 게시와 실제 URL 확인을 별도로 기록한다.
- 복구: 사이트 변경 커밋 되돌리기와 이전 정상 사이트 재배포. 게임 서비스·DB 상태에는 영향 없음.
- 종료 조건: 미리보기·독립 리뷰·검증 결과를 제공하고, 승인된 게시가 완료되면 실제 HTTPS URL/Actions 결과를 확인한다. 미실행·승인 대기·통과를 구분한다.

첫 웹 확인 이후 완료된 개발 묶음은 공개 원본과 선별 자료를 함께 갱신한다. 서버에 없는 기능이나 검증하지 않은 성공을 추가하지 않는다. 사이트 확인을 이유로 이미 통과한 Unity 배치를 반복하지 않는다.

# 맵 크기와 이동 템포 개선

기존 구역1~4의 좌표·폭100·전환 여백5·Cell22(5×5)을 유지하며 구역5~6을 추가해 3×2로 연결했다. 명목 탐험 면적은 40,000에서 60,000으로 50% 늘어난다. 저장된 구역/좌표를 재설정하거나 DB 형식을 변경하지 않는다.

유저 이동4unit/s와 클라이언트 예측 속도를 맞췄다. 몬스터 배회·귀환1.5unit/s, 추적 일반3/강화3.6/보스1.8unit/s다. 기존 개체별 상대 속도·서버 판정·현재 Cell 내 추적·귀환과 휴식은 유지한다. 이동 budget cap3은 0.75초분이며 임의의 즉시이동을 허용하지 않는다.

서버 배열과 ClientCore 패킷 범위, Unity 구역 표시·인접 판정을 함께6구역으로 맞췄다. 방향 op4개와 wire 구조는 불변이다. native 기존 몬스터2/확장 구역전환1 및 Unity 경계·패킷·예측속도 직접 검증 통과. 구역3↔6/4↔5↔6과 행 넘김·없는 구역 거부를 검증했다. Release 빌드 성공 후 서버43240 정상 기동. 실제 UI에서 새 필드를 걸어보는 검증은 Editor 연결 복구 후 통합 배치로 남긴다. 원본 서버 이미지·로그 보존, 강제 종료·DB 초기화 없음.

# 거래소

요약: 매물 조회·구매와 내 매물의 취소·수령을 한곳에서 확인하는 거래소 화면입니다.

상태: 중간 결과

## 구현한 기능

- 아이템 종류와 페이지를 골라 매물을 조회하고 가격·수량·판매 상태를 확인합니다.
- 매물을 선택하면 아이템 그림과 판매 정보를 확인합니다.
- 판매 검색과 내 매물 목록을 전환하고, 내 매물을 새로 조회합니다.
- 구매 전 가격을 확인한 뒤 구매를 요청하고 구매 결과와 가방 반영을 구분합니다.
- 내 판매 매물의 취소, 반환 아이템 수령, 판매 대금 수령을 각각 요청하고 서버 결과를 표시합니다.
- B 키로 거래소를 열고 닫습니다. 가방과 거래소는 한 번에 하나만 표시됩니다.

## 현재 확인한 범위

실제 서버에서 매물 조회, 빈 검색 결과, 재화 부족, 빈 내 매물과 빈 수령함을 확인했습니다. 본인 매물이 없을 때 취소와 수령 버튼이 비활성화되는 것도 확인했습니다. 성공 구매·취소·아이템 반환은 자동 검증으로 확인했으며, 실제 서버에서 성공 거래를 완료한 화면은 없습니다. 아이템 사용·장착과 거래 등록은 지원하지 않습니다. 아래 이력은 초기 조회·내 매물 화면에서 아이콘 목록과 구매·취소·수령 흐름으로 이어지는 화면을 모았습니다.

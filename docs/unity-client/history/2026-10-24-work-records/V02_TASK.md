# V02 — 정통 판타지 MMORPG 대표 화면

사용자: V01은 장난감 같다. 성인 캐릭터 비율·구조적인 장비 디테일·성숙한 판타지 배경과 일관된 UI를 요청했고 실행 테스트를 다시 재개했다. V01의 실행 보류는 이번 명시 지시로 해제한다.

범위: 대표 기사 외형1종, 기존 C02 로그인/선택/필드 화면만 개정. 7~7.5등신에 가까운 자연스러운 관절·판금 분절·가죽/체인메일·검/방패, 절제된 강철/천/청동, 깊이 있는 석조 관문·성벽·자연 지면/수목/원경. 기존 입력/목록/월드게이트와 실제 서버 데이터 유지. 신규 기능/가짜 수치/유료 구매/C01·런타임·ClientCore·서버·패키지 변경 제외.

소유권: v01_artist는 C02SceneBuilder.cs/Art/관련 시각 재질/C02.unity 및 Edit Mode Editor 단독 소유. root는 작업카드/기록/Slack. 정적 리뷰는 별도 리뷰어. 동결/조작권 반납 전 root는 Unity/Assets를 조작하지 않는다. 테스트 중 모두 Assets/Packages/ProjectSettings를 수정하지 않는다.

검증 목표: 최종 개정본이 실제 입력/로그인→목록→선택→Enter→서버 Zone+ownFull→좌표/월드 표시를 유지하고 UI/캐릭터/배경이 한 화면에서 읽힌다. 기존 검토된 StartLiveEntryUi(5011UL)를 재사용하며 실제 동작 한 번으로 UI와 새 AUTH 런타임 본인 진입을 함께 검증한다. 상태 주입은 실제 진입 근거로 사용하지 않는다.

포함 검증: 대상 해시/컴파일0/참조/목록폭/재생성저장 일관성의 정적 리뷰; 기존 GameView Mouse/문자 입력 helper 1회; 1280x720 로그인/목록/필드 PNG와 짧은 실제 결과상태 GIF; root 직접 이미지 확인; 정상 Play종료/연결해제/도우미·Recorder 정리. 실패/수정 시 영향 범위만 재실행. 서버 데이터 재생성/임의 계정·타인 접속/새 프로토콜/전체 fixture 반복 제외.

비용·종료: 대표1scene 저작과 1회 실제 flow(최대3분, 실패시 근거 확보·두 번 같은원인 수정 후 중단/재판단). 레이아웃 또는 저작 변경 후만 필요한 재검증. 정적 리뷰와 실제 flow/화면 판정/캡처가 완료되면 종료. 새 스타일을 실제 이미지로 사용자에게 보여주고 대량 아트 확장은 하지 않는다.

최신 사용자 지시: Unity 입력 테스트를 다시 잠시 보류하고 변경별 배치에 모은다. 실제 입력은 시작하지 않았고 INPUT_TEST_BATCH.md B01에 V02+새AUTH 본인진입 공통flow를 통합해 대기시켰다. 저작·컴파일·정적 리뷰는 계속한다. 프로젝트 전문 역할 고정 동시2명 제한은 해제했고 도구의 실제 슬롯·단일 파일/Editor 소유권은 유지한다.

최종 정적 리뷰 V02_REVIEW.md: 코드상 차단 문제 없음. 저작/컴파일/Editor 미리보기 확인 완료, 실제 입력·새서버 진입·실행 PNG/GIF는 B01 대기. Captures/v02-validation-summary.txt에 완료/미실행을 구분했다.

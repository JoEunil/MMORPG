# 인벤토리

요약: 아이템을 살펴보고, 사냥으로 얻은 포션을 사용해 체력을 회복하는 가방 화면입니다.
상태: 중간 결과

## 대표 화면

![일반 몬스터를 처치해 얻은 HP 포션을 선택한 실제 가방 화면](../../../site/media/releases/2026-10-29/growth-potion-before-use.png)

몬스터를 처치해 레벨이 오른 뒤 HP 포션을 선택한 실제 게임 화면입니다. 포션 그림·이름·수량과 사용 버튼을 함께 확인할 수 있습니다.

## 구현한 기능

AI Agent 작업에서 Unity 인벤토리 화면과 서버 조회를 새로 연결했습니다. 직접 구현한 기존 2D 클라이언트에는 인벤토리 화면이 없었습니다.

- 아이템 그림·이름·수량을 카드로 보여주고, 선택 항목은 오른쪽 상세 영역에서 확인합니다.
- 새로고침 후 같은 아이템의 선택을 유지하고 최신 수량을 보여줍니다. 아이템이 사라지거나 바뀌면 선택을 해제합니다.
- I 키로 열고 닫으며 Esc로 닫을 수 있습니다. 거래소와 동시에 띄우지 않습니다.
- 사냥 보상으로 받은 HP 포션을 가방에서 사용합니다. 1개로 HP 3,000을 회복하고, 재사용까지 2초 기다립니다. 사망 중이거나 HP가 가득 차면 소비하지 않습니다.
- 서버의 빈 가방 결과와 조회 오류를 구분합니다. 오류 뒤 한 번 다시 조회하고, 계속 실패하면 새로고침을 안내합니다.

가방과 거래소 판매 화면을 빠르게 전환해도 같은 조회를 재사용합니다. 아이템 수령·판매 취소가 뒤늦게 완료되면 열린 가방에 최신 목록을 반영합니다.

## 현재 확인한 범위

실제 거래 포션 수령과 사냥 보상 포션 사용 뒤 HP 회복·수량 감소를 확인하고, 재접속 후 상태 보존도 확인했습니다. I/B/Esc 전환과 선택·갱신·오류 복구는 각각 실제 입력 또는 자동 검사로 확인했습니다.
아이템 장착은 제공하지 않습니다.

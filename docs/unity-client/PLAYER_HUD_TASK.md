포함: C05 기존 Full HP/MP의 읽기 쉬운 게이지·정확한 수치, 기존3스킬/방향/HP0·transition·로그아웃·가방/거래소/채팅 키차단 유지, 기존 Scene 대상 Editor Setup의 제한된 배치. 가방의 기존 서버/DB 실패 원인 분석과 승인 범위 안의 정상 조회 검증, 최종 공개 설명과 실제 캡처.

제외: 레벨업/경험치 규칙·가짜 수치/쿨다운·새 스킬·아이템사용/장착·거래·스키마·직접DB쓰기·서버큐/락/캐시 의미 변경·추상화 프레임워크. DB누락은빈성공으로덮지않는다. 데이터 보완이 필요하면 정확한 후보와 복구/검증을 준비해 지정Slack앱승인뒤에만실행한다.

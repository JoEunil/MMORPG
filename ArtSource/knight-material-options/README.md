# 기사 갑옷 재질 비교안 — 2026-10-24

사용자 선택 전 에디터 시안이며 실제 게임 적용·사용자 선택 완료가 아니다. 기존 ObservedPlayer prefab의 TemperedSteel 슬롯을 임시 복제해 비교했다. 모델·텍스처·나머지 재질·카메라·광원·성채 반사 환경은 세 안에서 동일하다. 파일명 A/B/C와 채팅의 비교 이름이 대응한다.

| 안 | BaseColor RGB | Metallic | Smoothness |
| --- | --- | --- | --- |
| A 밝은 강철 | .78/.82/.86 | .76 | .62 |
| B 절제된 강철 | .62/.66/.70 | .76 | .40 |
| C 무광 흑철 | .43/.47/.51 | .76 | .28 |

B 추천은 과한 광택 배제를 고려한 제안이며 사용자의 확정 취향이 아니다. 원본 생성기를 실행하지 않았고 Scene·Prefab·Material을 저장하지 않았다. 처음 뒷모습 위주 시안은 비교에 부적합해 같은 앞 시점·반사 환경으로 다시 렌더했다. render-options.cs는 Assets 밖에서 실행하는 재현용 임시 렌더 스크립트다. 다음 변경 전 사용자 선택을 BRIEF에 범위와 함께 기록한다.

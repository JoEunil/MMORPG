# 내 매물 조회와 검색 전환

요약: 현재 캐릭터의 매물만 조회하고, 새로고침하거나 판매 검색으로 돌아갑니다.
상태: 검증된 결과

## 구현한 기능

- 판매 검색과 내 매물을 탭으로 전환합니다.
- 서버가 접속 중인 캐릭터를 확인해 해당 캐릭터의 매물만 조회합니다.
- 내 매물을 새로고침하고, 매물이 없을 때 정상 빈 결과를 표시합니다.
- 탭·접속·구역이 바뀐 뒤 도착한 이전 응답이 현재 화면을 덮지 않도록 처리합니다.

## 현재 확인한 범위

두 테스트 캐릭터로 내 매물의 빈 결과와 판매 검색 복귀를 확인했습니다. 실제 소유 매물이 있는 결과는 아직 확인하지 않았으며, 등록·구매·취소·수령은 지원하지 않습니다. 이후 목록과 선택 상세를 개선한 화면은 [아이템과 거래소 화면](/MMORPG/work/item-market/index.html)에서 볼 수 있습니다.

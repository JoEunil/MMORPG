# 거래소

요약: 매물을 조회하고, 판매·구매와 내 매물 관리를 확인하는 거래소 화면입니다.
상태: 중간 결과

## 구현한 기능

AI Agent 작업에서 Unity 거래소 화면과 기존 서버 연결을 새로 구현했습니다. 직접 만든 기존 2D 클라이언트에는 거래소 화면이 없었습니다.

- 종류별 매물 조회, 페이지 이동, 아이템 그림·수량·가격과 선택 상세를 표시합니다.
- 판매 검색과 내 매물, 수령함을 전환합니다.
- 구매, 판매 취소, 반환 아이템·판매 대금 수령을 각각 요청하고 서버 응답을 표시합니다.
- 가방에서 아이템과 수량을 골라 묶음 가격을 입력하고, 등록 전 골드 수수료를 확인합니다.
- 골드·다이아 잔액을 표시하고 거래 뒤 다시 조회합니다. 불확실한 결과는 성공으로 처리하거나 자동 재요청하지 않습니다.
- B 키로 열고 닫으며 가방과 거래소는 한 번에 하나만 표시합니다.

열린 거래소는 Esc로도 닫습니다. 닫기를 거래 취소나 실패 확정으로 취급하지 않으며, 결과가 불확실한 거래를 자동으로 다시 보내지 않습니다.

## 현재 확인한 범위

실제 서버 매물 조회, 검색 결과 없음, 재화 부족, 빈 내 매물·수령함을 확인했습니다. 내 매물이 없을 때 관련 버튼이 비활성화되는 것도 확인했습니다. 성공 구매·취소·아이템 반환은 자동 검증에서 확인했지만 실제 서버에서 성공 거래를 완료한 화면은 없습니다. 판매 등록의 수수료 계산과 구매 전 차감 다이아 확인은 자동 검증으로 확인했고, 실제 접속에서는 거래소 조회와 판매 탭 진입까지 확인했습니다. 판매 등록 완료와 실제 재화 차감은 미확인입니다. 아이템 사용·장착은 지원하지 않습니다.

화면 이력은 첫 거래소 조회부터 아이템 그림, 구매·수령, 내 매물, 판매 입력까지 이어집니다. 예시 수치가 든 에디터 화면과 실제 서버 응답을 캡션에서 구분했습니다.

# 사냥터·전투·포션 밸런스 제안

상태: 사용자가 추천안 전체 적용을 승인했다. 아래 수치는 승인된 초기값이며 구현·통합 검증 중이다. 기준은 PR67 후보의 서버 정본 데이터다. 몬스터 AI·배회·추적·공격 상태와 기존 phase 순서는 작업에서 제외한다.

## 비교와 추천

| 안 | 범위 | 장단점 |
| --- | --- | --- |
| 최소 보정 | Q피해300·Q MP0, E/R피해1000 유지·MP100/160, HP1500·MP500·공용6초. 기존 구역 몬스터 능력치/EXP/골드/112마리 배치는 유지 | 변경은 작지만 구역별 차이가 약하다. |
| 구역별 재구성 — 추천 | 아래 전투·회복 수치와 Zone별 능력치·보상·스폰 구성을 함께 조정 | 구역마다 위험·보상이 달라진다. 스킬 공유 분리와 구역별 데이터 연결이 추가로 필요하다. |

## 전투·회복 추천값

캐릭터 공격력10 기준 피해. 저장 공격력이 다르면 실제 피해도 비례한다. 성장 상한100과 레벨당 HP+500을 유지하며 자동 공격력 성장·기존 캐릭터 수치 초기화는 추가하지 않는다.

| 항목 | 현재 | 추천 |
| --- | --- | --- |
| Q 기본 공격 | 피해50 / MP1 / 쿨1초 | 피해300 / MP0 / 쿨1초 |
| E 원형 공격 | 피해1000 / MP20 / 쿨6초 | 피해1200 / MP100 / 쿨6초 |
| R 전방 공격 | 피해1000 / MP20 / 쿨4초 | 피해1800 / MP160 / 쿨4초 |
| HP 포션 | 3000 회복 | 1500 회복 |
| MP 포션 | 3000 회복 | 500 회복 |
| 포션 공용 쿨 | 2초 | 6초 |
| 일반·강화 처치 포션 | HP1개+MP1개 확정 | 유지 |
| 패링 | 유효0.25초 / 쿨3초 / 특수 공격1회 | 유지 |

Q/E/R의 범위·타격 시점·기존 모션은 이번 수치 조정에서 유지한다. 몬스터와 플레이어가 현재 skill0/1을 공유하므로 무작정 공유 계수를 바꾸지 않는다. 플레이어/몬스터 밸런스 정의를 구분하고 기존 몬스터 공격 순서와 행동은 유지한다. 정확한 데이터/스킬ID·클라이언트표현 연결은 구현 전에 호출부를 확인한다.

MP0에도 Q로 계속 사냥할 수 있다. MP포션500은 E5회 또는 R3회분(20MP 잔여)이다. HP/MP 공유6초 때문에 회복 대상을 선택하되 새 상점·회복원·확률 드랍은 요구하지 않는다. 확정 드랍 유지는 편의 우선이며 장기 포션 재고가 쌓이지 않는 경제까지 보장하지 않는다.

## 구역 구성 추천

몬스터 수는 저작 목표 총수이며 실배치는 통행 가능한 위치와 길·진입부 여백을 검증해 맞춘다. 현재 사냥터는 각 일반94+강화17+보스1=112마리다. 입장 레벨 제한을 추가하지 않고 아래는 권장 구간이다.

| 구역 | 권장 레벨 | 일반/강화/보스 목표 | 일반HP / 강화HP | 일반 기본피해 / 강화 기본·특수 피해 | 일반 EXP / 골드 |
| --- | --- | --- | --- | --- | --- |
| Zone1 마을 | 공통 | 0 / 0 / 0 | — | — | — |
| Zone2 성문 밖 | 1~5 | 108 / 12 / 0 | 900 / 2000 | 250 / 400·1200 | 10 / 10 |
| Zone3 외곽 초지 | 6~10 | 116 / 16 / 0 | 1200 / 2800 | 350 / 550·1650 | 25 / 15 |
| Zone4 폐허 길목 | 11~15 | 123 / 20 / 1 | 1600 / 3800 | 450 / 750·2250 | 40 / 20 |
| Zone5 성곽 외곽 | 16~20 | 132 / 24 / 0 | 2100 / 5000 | 600 / 950·2850 | 55 / 30 |
| Zone6 깊은 사냥터 | 21~25 | 139 / 28 / 1 | 2700 / 6500 | 750 / 1200·3600 | 70 / 40 |

명칭은 화면 안내용 가칭이며 지형을 새로 만들었다는 뜻이 아니다. 강화 몬스터 EXP·골드는 해당 일반의3배를 추천한다. 일반은 길 바깥 군집, 강화는 더 안쪽, 보스는 통행로와 분리된 안쪽 공간에 두는 배치 방향이다. 시야 확보·진입부 비움 원칙을 유지하며 이동 AI/장애물 길찾기는 변경하지 않는다.

보스는 Zone4 HP24000/적중 phase당1800/EXP1200, Zone6 HP36000/적중 phase당3000/EXP2100을 추천한다. 골드·포션은 현행처럼 보스에게 추가하지 않는다. 기존3단계 공격 패턴·phase 순서·재생성 주기는 유지하며 수치와 스폰만 조정한다. 다단 phase가 모두 맞으면 총피해는 phase별 피해 합계다.

## 숫자를 읽는 기준

- 일반 몬스터는 Q만 쓸 때 Zone2부터 약3/4/6/7/9회 적중이 필요하다. E/R을 섞으면 줄어든다. 재사용·예고·빗나감·이동을 포함한 실제 처치 시간은 측정 전이다.
- 기존 성장식 누적EXP=25×L×(L−1)을 유지한다. Lv1→6, 6→11, 11→16, 16→21, 21→26의 각 5레벨 진행에 약75/80/82/82/83마리가 필요하다. 강화·보스를 잡으면 줄어든다. 플레이 시간이나 경험치 효율을 실측했다고 주장하지 않는다.
- 성장에 공격력 보너스가 없으므로 적HP를 레벨에 비례해 크게 부풀리지 않는다. 난이도는 피해·군집·강화비율·기존 공격 조합과 함께 만든다.
- 위 피해는 최종 적중 피해 목표이며 현재 attack×phase계수 데이터로 표현 가능한지 정수 범위를 확인한다. 방어력·레벨 차 명중률·새 피해 공식을 추가하지 않는다.

## 변경 경계와 선택

서버 정본 전투/아이템·구역 스탯/보상 데이터와 기존 exporter/importer, Unity 저작 스폰 데이터에 연결한다. 현재 구역별 능력치·보상·몬스터 레벨 표시는 완성돼 있지 않으므로 새 데이터 연결 작업임을 명시한다. 몬스터 AI·새 장비·등급 포션·수령함·DB 스키마는 제외한다.

사용자는 추천 묶음 전체 적용을 선택했다. 한 기능 묶음으로 구현·리뷰하고 변경 직접 영향만 최소 검증한다. 작은 수치마다 다시 묻지 않는다.

근거: CoreLib/Monsters.inc, Skills.inc, Growth.inc, ItemData.h, SkillData.h, ZoneState_Skills.cpp 및 UnityClient/Exports/ServerData/MonsterSpawns.inc. 서버 정본→클라이언트 공유와 Unity 맵/스폰→서버 경로를 유지한다.
